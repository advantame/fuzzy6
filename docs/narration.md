# 語りの書き方（VOICEVOX）

語りの原稿を、VOICEVOX で自然に読ませるための決まりです（2026-10-11）。利用者の経験と Engine 0.25.2 のコードを調べた [research/voicevox-writing/report.md](../research/voicevox-writing/report.md) から、このリポジトリで使う分だけを抜き出しました。出典と確かさは、そちらにあります。記法と道具の契約は [spec.md](spec.md) の §6.6、§7.1、§7.3 です。

ここに書いた規則の多くは、一人か二人の利用者の経験です。採るかどうかは、最後は聞いて決めます。Claude は音を聞けないので、確かめられるのは読み（カナ）と、拍ごとの高さと長さの数字までです。

## 直す順序

1. 読みを確かめる。合成のあとに出る読み（カナ）を見る。
2. アクセントを直す。どこで下がるか、どこで句が切れるか。
3. 長さを直す。長音が短い、間が長い、など。
4. 何度も出る語は、語彙に入れる。

問題のない語には手を付けません。カタカナ語を一律に平板にする、といった広い規則は作りません。

## どこに書くか

| 直したいこと | 書く場所 |
|---|---|
| 一か所の読み | 原稿の `[表記\|よみ]` |
| 語の読みとアクセント（デッキのどこでも） | `voice.lexicon` の `kana` と `accent` |
| 長音が短く、弱く聞こえる | `voice.lexicon` の `long` |
| 話す速さ | 文の `speed`（`'slow'` / `'fast'`） |
| 途中で待たせる | 文を分ける。声の外の間は `rest` |

いまの道具では、次のことはできません。必要になったら、仕様に足します。

- アクセント句の切れ目を指定する。
- 拍ごとの高さを直接書く。
- 読点の間の長さを、一か所だけ変える。
- 文末の上げ下げを指定する（「？」で終わる文は、エンジンが語尾を上げます）。

## アクセント

- **アクセントの番号は、下がり目の位置です。** 上げたい所の番号ではありません。「低く始めて途中で上げ、あとは高いままにする」のは平板で、`accent: 'flat'` と書きます。
- 平板の語に助詞が続くと、助詞まで高いまま続きます。句の形はエンジンが決めるので、語彙には語だけを書きます（「ChatGPT へと」の「へと」は書かない）。
- 番号を書くときは、拍で数えます。「チャ」「ティ」のような拗音は 1 拍、「ッ」「ー」「ン」も 1 拍です。
- 英語の略語（GPT、MCP、LLM、API、AI など）には、利用者のあいだで決まったアクセントがありません。読みを語ごとに決め、聞いて直します。

## 長音

- 「ツール」を「ツウル」と書いても、長くはなりません。エンジンの中では、もともと同じ拍の並びだからです。
- 長音が弱いときは、長音の拍の母音を伸ばします（`long`）。値に定石はなく、聞いて決めます。
- 話速を上げると、長音も同じ割合で短くなります。基本の速さ（1.3）で決めたあと、ゆっくりと早口でも確かめます。

## 数字、単位、記号

- 数字に単位の記号が付くと、記号を字のまま読むことがあります（「2m」を「ニエム」）。読みを書きます。例: `[2m|2メートル]`、`[5℃|セッシゴド]`。
- 分数、小数、範囲、番号、負の数は、意味を選んで読みを書きます。例: `[1/3|サンブンノイチ]`、`[1〜3|イチカラサン]`、`[-3|マイナスサン]`。
- 年（「1948 年」「2021 年」）は、そのままで正しく読まれた報告が多く、いまの 1-1 でも正しく読まれています。
- 「＋」「＝」のような演算の記号は、読みを書きます。見比べる式は、字幕ではなく図の中に書きます（AGENTS.md の「表現の決まり」）。

## 助詞、読みの分かれる語

- ひらがなの「は」は、語の一部でも助詞として「ワ」と読まれることがあります。あいまいな語は、読みをカタカナで書きます。
- 読みをカタカナで書くとき、助詞の「は」「へ」は、発音のとおり「ワ」「エ」と書きます。
- 同じ字で読みの違う語（「中日」「方」「日本橋」）は、意味に合う読みを書きます。
- 漢字、ひらがな、カタカナのどれで書けば安定する、という決まりはありません。字幕の表記はそのままにして、あいまいな語にだけ読みを付けます。

## 句読点と間

- 読点や句点が何秒の間になるかは、決まっていません。間を秒で決めたいときは、文を分けて `rest` を使います。
- 空白を、間の記法として使いません。このリポジトリの読み上げの文は、日本語の字に接する半角の空白を取り除きます。
- かぎ括弧や引用符で入る間を、まとめて消すことはしません。意図した「ため」まで消えて棒読みになった、という報告があります。

## 話者

- 同じ読みとアクセントでも、話者が変わると高さと長さは変わります。四国めたんで決めた語彙を、ずんだもんでそのまま正しいと見なさず、聞いて確かめます。

## 確かめ方

1. `npm run narrate -- <deck> <clipId>` で、読み上げの文と、効く語彙を見る。
2. `npm run narrate -- <deck> <clipId> --inspect` で、拍ごとの高さと長さを見る。平板にした語の句で、高さが途中で下がっていないこと、伸ばした長音の拍が、前後の拍より短くないことを確かめる。
3. 合成して、聞く。聞いて決めたことは、デッキの README に日付と一緒に書く。

# Motion Explorer 仕様

版 0.5（2026-10-11 改訂）。この文書は、エクスプローラの共通部品と、デッキ・クリップ・テーマの契約の正本です。実装（`src/explorer/`）とこの文書が食い違ったら、どちらを正とするか決めて、両方をそろえます。

## 1. 何をするものか

短いモーション（クリップ）を束ねて、矢印キーで行き来しながら見ていくウェブアプリです。↑ と ↓ でクリップを移り、← と → でクリップの中の止まりを移ります。クリップは数秒から 90 秒までのアニメーションで、時刻の純粋関数として描きます。クリップには語りの音声と字幕を付けられます。

テーマごとに見た目は大きく変えてかまいません。テーマが変えないのは次の三つです。

- 画面の幾何（L 字の枠と、1600×900 のステージ）
- 部品の構造と振る舞い（パンくず、題名、デッキの軸、シークバー、字幕、ナビ、目次）
- デッキとクリップの契約（データの形、時刻の扱い、確認用の URL）

### 用語

| 用語 | 意味 |
|---|---|
| デッキ (deck) | 一つのテーマのクリップの束。例: LLM |
| 章 (chapter) | デッキの中の区切り。クリップを順に並べたもの |
| クリップ (clip) | 一本の短いモーション。時刻 t の純粋関数として描く |
| 語り (narration) | クリップに付ける声。文ごとに合成した音声と、その字幕からなる |
| 語り手 (speaker) | 語りの声の主。デッキの配役（cast）に並べ、文が選ぶ |
| 立ち絵 (figure) | 語り手の絵。字幕の帯の端に出し、声に合わせて口を動かす |
| 文 (line) | 語りの一文。一度に合成する単位で、字幕の一枚にあたる |
| 印 (anchor) | 文の中の位置に付ける名前。声がそこへ来る時刻を指す |
| 時間割 (timeline) | 声の長さと歩調から計算した、クリップの中の時刻の割り付け |
| 止まり (stop) | ← → で移る先。文の頭と静止点の二種類がある |
| 静止点 (still) | 声と動きが終わり、絵が一枚の図版として読める時刻 |
| 歩調 (pace) | 間の長さや入りの速さなど、どのクリップにも効く時間の変数 |
| 字幕 (cue) | クリップの時刻の区間に結びついた文 |
| ステージ (stage) | クリップを描く 1600×900 の領域 |
| 枠 (chrome) | ステージの左と下を囲む L 字の領域 |
| テーマ (theme) | デッキの見た目。CSS 変数、CSS、飾りの DOM で与える |

## 2. 画面の幾何

論理座標 1920×1080 で設計し、全体を一様に拡大縮小してウィンドウに収めます。1760×990 のウィンドウでは 11/12 倍、1600×900 では 5/6 倍になり、どれでも同じ絵です。16:9 でないウィンドウでは、余った側に帯が出ます（帯の色は `--mx-bg`）。

```
x: 0          320                                        1920
y: 0  ┌────────┬──────────────────────────────────────────┐
      │        │                                          │
      │  rail  │                 stage                    │
      │320×900 │               1600×900                   │
      │        │                                          │
  900 ├────────┼──────────────────────────────────────────┤
      │ corner │                  bar                     │
      │320×180 │               1600×180                   │
 1080 └────────┴──────────────────────────────────────────┘
```

- ステージの 1600×900 は、画面全体と相似の 16:9（画面の 5/6）です。クリップはこの論理座標で描きます。
- L 字の内側の二辺を、二本の軸として扱います。横の辺（ステージの下端、y = 900）はシークバーで、クリップの中の時刻を表します。縦の辺（ステージの左端、x = 320）はデッキの軸で、デッキの中の位置を表します。二辺が交わる角（corner）に、現在の番号と前後のボタンを置きます。
- 四つの領域の位置と大きさは固定です。テーマは色、書体、飾りを変えますが、寸法は変えません。

デッキは、枠の右に余白の列（gutter）を足せます（`deck.frame.gutter`、§7）。幅を g とすると、次のようになります。

- 論理座標は (1920 + g)×1080 になります。g = 120 で、全体が 17:9 です。
- bar は右へ g だけ伸び、幅 1600 + g になります。rail、stage、corner の位置と大きさは変わりません。中身は左に詰めたままで、増えるのは右の端だけです。
- ステージの右の列（x = 1920 から、幅 g、高さ 900）は `.mx-gutter` です。既定では何も置きません。
- シークバーは、ステージの下端に沿ったまま、幅 1600 から伸びません。
- 拡縮は、(1920 + g)×1080 がウィンドウに収まるように行います。`&clean` のモード（§8）では、gutter を使いません。

ふつうのブラウザのウィンドウは 16:9 より横に長く、16:9 の枠では左右が余ります。gutter は、その幅を、bar の端に立つ立ち絵（§3.4）に使うためのものです。全画面の 16:9 では、上下に帯が出て、絵は少し小さくなります（g = 120 で約 6%）。

## 3. 部品

### 3.1 全体

```html
<div class="mx" data-deck="llm" data-chapter="history" data-clip="shannon" data-state="playing">
  <div class="mx-frame">                  <!-- 1920×1080。JS が transform で拡縮し、中央に置く -->
    <aside class="mx-rail">…</aside>      <!-- 3.2 -->
    <main class="mx-stage">…</main>       <!-- 3.3 -->
    <div class="mx-corner">…</div>        <!-- 3.5 -->
    <footer class="mx-bar">…</footer>     <!-- 3.4 -->
    <div class="mx-gutter"></div>         <!-- §2。deck.frame.gutter が 0 より大きいときだけ置く -->
    <div class="mx-index" hidden>…</div>  <!-- 3.6。ステージの領域に重なる -->
  </div>
</div>
```

`.mx` の属性。テーマの CSS は、これを見て見た目を切り替えます。

| 属性 | 値 |
|---|---|
| `data-deck` | デッキの id |
| `data-chapter` | 現在の章の id |
| `data-clip` | 現在のクリップの id |
| `data-state` | `loading` / `playing` / `paused` / `ended` |
| `data-dir` | 直前の移動の向き。`next` / `prev` / `jump` |
| `data-auto` | 「自動で次へ」が有効なとき付く |
| `data-index` | 目次が開いているとき付く |
| `data-first` / `data-last` | 最初・最後のクリップのとき付く |
| `data-still` | 静止フレームのモード（§8）のとき付く |
| `data-clean` | 枠を消すモード（§8）のとき付く |
| `data-sound` | 語りの音声の状態。`on` / `off` / `blocked`（ブラウザが音を止めている。§5.2） |
| `data-subs` | 字幕を隠しているとき `off`。出しているときは付けない |
| `data-landing` | 静止点へ跳んで、着地の間（§5）だけ時計を止めているとき付く |
| `data-tune` | 調整用のパネル（§8.1）を開いているとき付く |
| `data-cast` | 立ち絵（§3.4）を一つ以上出しているとき付く |
| `data-gutter` | 枠の右に余白の列（§2）があるとき付く |

JS が書く CSS 変数。

| 変数 | 要素 | 値 | 更新 |
|---|---|---|---|
| `--mx-k` | `.mx` | 拡縮の倍率 | リサイズのとき |
| `--mx-gutter` | `.mx` | 余白の列の幅（§2）。`120px` のように単位を付ける。なければ `0px` | 作るとき |
| `--mx-deck-progress` | `.mx` | デッキの中の位置。0〜1（最初のクリップで 0、最後で 1） | 移動のとき |
| `--mx-progress` | `.mx-seek` | クリップの中の進み。0〜1 | 描くたび |
| `--mx-t`, `--mx-p` | `.mx-layer` | そのクリップの時刻（秒）と進み（0〜1） | 描くたび |

ページの `document.title` は「クリップの題名 — デッキの title」にします。

### 3.2 rail（パンくず、題名、デッキの軸）

```html
<aside class="mx-rail">
  <nav class="mx-crumbs" aria-label="現在地">
    <button class="mx-crumb" data-level="deck">LLM</button>
    <button class="mx-crumb" data-level="chapter"><span class="mx-crumb-no">1</span><span class="mx-crumb-name">歴史</span></button>
  </nav>
  <header class="mx-heading" aria-live="polite">
    <div class="mx-heading-body">
      <p class="mx-no"><span class="mx-no-chapter">1</span><span class="mx-no-sep">-</span><span class="mx-no-clip">3</span></p>
      <h1 class="mx-title">次の文字を当てる</h1>
      <p class="mx-kicker">1948 · Claude Shannon</p>
    </div>
  </header>
  <ol class="mx-axis" aria-label="クリップの並び">
    <li class="mx-tick" data-chapter="history" data-chapter-start data-state="past">
      <button tabindex="-1" data-clip="opening" data-label="1-1 LLM"></button>
    </li>
    …
  </ol>
  <footer class="mx-credits"><p class="mx-credit">VOICEVOX:四国めたん</p></footer>
</aside>
```

- パンくずは「デッキ / 章」の二段です。どちらを押しても目次（3.6）が開きます。章を押したときは、その章の最初の項目にフォーカスを置きます。
- `.mx-credits` は、配役の `credit`（§7.2）と `deck.credits`（§7）の文字列を、一つずつ `.mx-credit` にして並べます。配役の表記が先で、同じ文字列は一度だけ出します。どちらもなければ置きません。
- `.mx-heading-body` は、クリップが変わるたびに新しい要素に差し替えます。CSS アニメーションを毎回最初から流すためです。古い要素には `data-out` を付け、`animationend` で取り除きます（アニメーションがなければ 600ms 後）。同時に存在するのは 2 つまでです。
- `.mx-no` は章の中の番号です。`numbered: false` のクリップ（扉など）では置きません。`.mx-kicker` は `clip.kicker` があるときだけ置きます。
- `.mx-axis` はデッキの全クリップを順に並べた目盛りです。章の最初の目盛りに `data-chapter-start` を付けます。`data-state` は `past` / `current` / `future` です。テーマが縦の辺に沿って描きます。目盛りの button を押すと、そのクリップへ移ります。button の `data-label` は「番号 題名」で、テーマが吹き出しに使えます。目次があるので、目盛りは Tab の対象にしません（`tabindex="-1"`）。

### 3.3 stage

```html
<main class="mx-stage" aria-label="次の文字を当てる">
  <div class="mx-layer" data-clip="turing" data-role="out">…</div>
  <div class="mx-layer" data-clip="shannon" data-role="current">…</div>
</main>
```

- 1600×900 で、はみ出しは隠します。
- クリップごとに `.mx-layer`（1600×900）を一枚作り、`clip.setup` に渡します（§6）。
- 切り替え: 新しい層を `data-role="in"` で置き、スタイルを一度確定させてから（次のフレームで）`current` に変えます。古い層は `data-role="out"` にして、`transitionend` で dispose して取り除きます（トランジションがなければ 700ms 後）。向きは `.mx[data-dir]` で CSS が知ります。
- ステージを押す（タップする）と、再生と一時停止が切り替わります。タッチで 60px 以上スワイプすると移動します。左へ払うと次の止まり、右へ払うと前の止まり、上へ払うと次のクリップ、下へ払うと前のクリップです。縦と横は、動いた量の大きい方で決めます。
- ブラウザが音を止めているとき（§5.2）は、ステージの中央に `<button class="mx-unlock">` を出します。文言は「音声つきで再生」です。押すと音声を有効にして再生を始め、ボタンを取り除きます。

### 3.4 bar（シークバーと字幕）

```html
<footer class="mx-bar">
  <div class="mx-seek" role="slider" tabindex="0" aria-label="再生位置"
       aria-valuemin="0" aria-valuemax="14" aria-valuenow="3.2" aria-valuetext="0:03 / 0:14"
       style="--mx-progress: 0.23">
    <div class="mx-seek-track"></div>
    <div class="mx-seek-fill"></div>
    <div class="mx-seek-marks">
      <button class="mx-seek-mark" tabindex="-1" style="--at: 0.06" data-time="0:00" data-kind="line"></button>
    </div>
    <div class="mx-seek-target" style="--at: 0.31" data-kind="stop"></div>
    <div class="mx-seek-head"></div>
    <div class="mx-seek-hover" hidden style="--at: 0.4">
      <span class="mx-seek-hover-time">0:05</span>
      <span class="mx-seek-hover-text">前の文字を多く見るほど、英語らしくなる。</span>
    </div>
  </div>
  <div class="mx-time"><span class="mx-time-now">0:03</span><span class="mx-time-sep">/</span><span class="mx-time-all">0:14</span></div>
  <div class="mx-subs" aria-live="polite">
    <p class="mx-cue" data-state="in">1948 年、シャノンは<strong>次の文字の確率</strong>で英文を作った。</p>
  </div>
</footer>
```

シークバー

- バーの上辺、つまりステージとの境目に沿って置きます。`--mx-progress` を描くたびに書き換えます。
- 押す、または引きずると、その時刻へ移ります。引きずっている間は時計を止め、離したら元の再生状態に戻します。
- マウスやタッチで押しても、フォーカスは取りません。← → が止まりの移動のまま残るようにするためです。Tab でフォーカスしたときだけ、← → で 1 秒、Shift 付きで 5 秒、Home / End で頭と終わりへ動かします。
- 目印 `.mx-seek-mark` は、クリップの止まり（§6.8）に一つずつ置きます。`data-kind` は `line`（文の頭）か `still`（静止点）です。時刻 0 の止まりにも置きます。目印を押すと、その時刻へ移ります。
- `.mx-seek-target` は、いま → を押したときの行き先を示します。`--at` は行き先の時刻をクリップの長さで割った値、`data-kind` は止まりへ跳ぶなら `stop`、秒で送るなら `skip` です。行き先がこのクリップの中にないとき（終わりにいるとき）は `hidden` にします。値が変わるときだけ書き換えます。
- ポインタを載せている間は `.mx-seek-hover` を出し、その位置の時刻と、その時刻に出ている字幕の文を見せます（なければ文は空）。
- 時刻の表示は `m:ss` です。

字幕

- 語りの原稿（§6.6）を持つクリップでは、文ごとに一つの cue を作ります。文 i の cue は、文 i の声の始まりから、次に声のある文の声の始まりまで出します。最後の文の cue は、クリップの終わりでも出したままにします。声のない文は cue を作りません。
- 原稿を持たないクリップでは、`clip.cues` をそのまま使います。
- 時刻 t で有効な cue（`at ≤ t < to`）をすべて、`at` の順に `<p class="mx-cue">` で出します。
- cue の文は HTML としてエスケープしたうえで、`**…**` を `<strong>`、`\n` を `<br>` にします。
- 再生中に cue が入れ替わるときは、入る cue に `data-state="in"`、出る cue に `data-state="out"` を付けます。出る cue は `animationend` で取り除きます（アニメーションがなければ 500ms 後）。`.mx-cue` の要素は、出ていくものを含めて 4 つまでです。
- 有効な cue が変わらないフレームでは、字幕の要素を移動・再挿入しません。新しい cue だけを `at` 順の位置に一度挿入し、登場アニメーションの再始動を防ぎます。
- シークや移動で時刻が飛んだときは、演出なしで入れ替えます。そのフレームだけ `.mx-subs` に `data-instant` を付けます。
- C キーで字幕を隠したり出したりできます。隠している間は `.mx` に `data-subs="off"` を付け、既定の CSS が `.mx-subs` を見えなくします。要素の出し入れは続けます。
- 原稿から作った cue の `<p class="mx-cue">` には、その文の語り手の id を `data-by` に付けます。テーマは、これで語り手ごとに字幕の色を変えられます。

立ち絵

```html
<footer class="mx-bar">
  …
  <div class="mx-cast" data-id="metan" data-side="left" role="img" aria-label="四国めたん"
       data-mouth="a" data-eyes="open" data-speaking style="--mx-figure-ratio: 0.92">
    <img class="mx-cast-base" src="…" alt="">
    <img class="mx-cast-eyes" data-shape="open" src="…" alt="">
    <img class="mx-cast-eyes" data-shape="closed" src="…" alt="">
    <img class="mx-cast-mouth" data-shape="x" src="…" alt="">
    <img class="mx-cast-mouth" data-shape="a" src="…" alt="">
    …
  </div>
  <div class="mx-subs">…</div>
</footer>
```

- いまのクリップに出る語り手のうち、立ち絵（`figure`、§7.2）を持つものを、一人につき一つの `.mx-cast` にして、`.mx-bar` の中の `.mx-subs` より前に置きます。
- 出る語り手は、既定では、そのクリップの原稿の中で話す語り手です。`clip.cast` に id の並びを書くと、その語り手を出します（話さない聞き手も出せます）。空の並びなら、だれも出しません。原稿を持たないクリップでは、`clip.cast` に書いた語り手だけを出します。
- `data-side` は `left` か `right` で、bar の左右の端にあたります。一つのクリップで、同じ側に二人は出せません。重なったら、そのクリップはエラーにします（§6.5）。
- 画像は、同じ大きさのものを重ねます。下から `.mx-cast-base`、`.mx-cast-eyes`、`.mx-cast-mouth` の順です。目と口は、形ごとに一枚ずつ `<img>` を置いておき、`.mx-cast` の `data-eyes` と `data-mouth` に合う一枚だけを、既定の CSS が見せます。`src` を差し替えないのは、切り替えのたびに読み込みで絵が欠けないようにするためです。`.mx-cast` の `--mx-figure-ratio` には、画像の幅を高さで割った値を書きます。既定の CSS は、これで立ち絵の幅を決めます。
- `data-mouth` は、いまの口の形です。`x`（閉じ）、`a` `i` `u` `e` `o`、`n`（ん）の七つがあります。その語り手の文の声が鳴っている区間（`voice_i ≤ t < end_i`）では、録りの口の動き（§7.1 の `mouth`）から、時刻 `t − voice_i` の形を取ります。それ以外の時刻は `x` です。録りのない文（見積もった文）と、録りに `mouth` のない文では、声の頭から 0.14 秒ごとに `a` と `x` を交互にします。
- 立ち絵にその形の画像がないときは、近い形で代えます。`i` は `e`、なければ `a`。`e` は `a`。`u` は `o`、なければ `a`。`o` は `a`。`n` は `x`。`data-mouth` には、代えたあとの形を書きます。
- `data-speaking` は、その語り手の声が鳴っている区間で付けます。
- `data-eyes` は `open` か `closed` です。まばたきも時刻の純粋関数にします。語り手ごとに、クリップの id と語り手の id から決まる疑似乱数で、2〜6 秒おきに 0.12 秒だけ `closed` にします。目の画像を持たない立ち絵には、この属性を付けません。
- 属性は、値が変わるときだけ書き換えます。クリップが変わっても、同じ語り手が同じ側に出続けるなら、要素を作り直しません。
- 静止フレームのモード（§8）でも出します。口と目は、同じ計算で決まります。このモードでは、出す立ち絵の画像の読み込みを待ってから、絵を描き終えたことにします（`__ready`、`__go`）。読み込めない画像があっても、3 秒で待つのをやめます。
- 立ち絵を出している間は、`.mx` に `data-cast` を付けます。既定の CSS は、立ち絵の幅だけ字幕の箱を両側から狭めます。片側にしか出ていなくても両側を狭めるのは、字幕が中央からずれないようにするためです。そのため、立ち絵を出すクリップの字幕は、1 行を全角 32 字までにします。
- 立ち絵の大きさは、既定では高さ 168px で、bar に収まります。テーマは `--mx-cast-h`（高さ）と `--mx-cast-w`（幅の上限）で変えられます。bar より高くすると、ステージの下の隅に重なります。シークバーは、立ち絵より手前に描きます。立ち絵ごとに大きさを変えることや、字幕の箱を立ち絵のある側だけ狭めることは、テーマが決めてかまいません。
- `&cast=0` で開いたときと、`setCast(false)` を呼んだあとは、立ち絵を出しません（§8）。

### 3.5 corner（現在の番号とナビ）

```html
<div class="mx-corner">
  <button class="mx-prev" aria-label="前のクリップ（↑）"><span class="mx-icon"></span></button>
  <div class="mx-count"><span class="mx-count-now">07</span><span class="mx-count-sep">/</span><span class="mx-count-all">28</span></div>
  <button class="mx-next" aria-label="次のクリップ（↓）"><span class="mx-icon"></span></button>
  <button class="mx-play" aria-label="再生 / 一時停止（Space）"><span class="mx-icon"></span></button>
  <button class="mx-auto" aria-pressed="false" aria-label="自動で次へ（A）"><span class="mx-icon"></span><span class="mx-auto-label">自動</span></button>
  <button class="mx-sound" aria-pressed="true" aria-label="音声（M）"><span class="mx-icon"></span><span class="mx-sound-label">音声</span></button>
</div>
```

- 最初のクリップでは `.mx-prev` を、最後のクリップでは `.mx-next` を disabled にします。
- `.mx-sound` は、デッキが語りの音声（§7.1）を持つときだけ置きます。`aria-pressed` は、音声が入なら `true`、切なら `false` です。
- 番号はデッキ全体の通し番号で、2 桁にそろえます（100 以上は 3 桁）。
- アイコンはテーマの CSS が `.mx-icon` に描きます。
- 枠のボタンは、マウスで押してもフォーカスを取りません（Space が直前のボタンの押し直しにならないように）。Tab で移って押す使い方は残します。

### 3.6 目次（index）

```html
<div class="mx-index" role="dialog" aria-label="目次" hidden>
  <header class="mx-index-head">
    <p class="mx-index-deck">LLM</p>
    <h2 class="mx-index-title">次の一語から、エージェントまで</h2>
  </header>
  <div class="mx-index-chapters">
    <section class="mx-index-chapter" data-chapter="history">
      <h3 class="mx-index-chapter-title"><span class="mx-index-chapter-no">1</span>歴史</h3>
      <ol class="mx-index-clips">
        <li><button class="mx-index-clip" data-clip="shannon" aria-current="true">
          <canvas class="mx-index-thumb"></canvas>
          <span class="mx-index-no">1-3</span><span class="mx-index-name">次の文字を当てる</span>
        </button></li>
      </ol>
    </section>
  </div>
</div>
```

- ステージの領域（x 320, y 0, 1600×900）に重ねます。枠は見えたままです。
- 開く: I、パンくずを押す。閉じる: Esc、I、項目を選ぶ、目次の外（枠）を押す。
- 開いている間は再生を止め、閉じたら元の状態に戻します。項目を選んだときは、そのクリップを頭から再生します。
- 開いた直後は、現在のクリップの項目にフォーカスを置きます。矢印キーで項目を移ります（↑ ↓ は章の中で、端では止まる。← → は隣の章の同じ段。段がなければ最後の項目）。Enter で選びます。
- 縮小図 `.mx-index-thumb`: 目次を開いたとき、まだ描いていないものを 1 フレームに 1 枚ずつ描きます。`stage.thumb = true` で setup を一度呼び、`clip.poster`（既定は duration）の時刻を描いて、すぐ dispose します。縮小先の canvas は画像補間を有効にし、品質を `high` にします。描いた縮小図は保持してかまいません。

## 4. 操作

| 操作 | キー | ほかの手段 |
|---|---|---|
| 次の止まり / 前の止まり | → / ← | 左へ / 右へスワイプ、シークバーの目印 |
| 次のクリップ / 前のクリップ | ↓ / ↑、PageDown / PageUp | `.mx-next` / `.mx-prev`、上へ / 下へスワイプ |
| 最初 / 最後のクリップ | Home / End | |
| 再生 / 一時停止 | Space / K | ステージを押す、`.mx-play` |
| 頭から再生 | R | |
| 2 秒戻る / 進む | Shift + ← / Shift + → | |
| 章の頭へ | 1〜9 | |
| 目次を開く / 閉じる | I（閉じるのは Esc も可） | パンくずを押す |
| 音声の入 / 切 | M | `.mx-sound` |
| 字幕を出す / 隠す | C | |
| 自動で次へ（切り替え） | A | `.mx-auto` |
| 全画面 | F | |

矢印キーの向きは、枠の二本の軸（§2）に合わせてあります。← → は横の軸（クリップの中の時刻）を、↑ ↓ は縦の軸（デッキの中の位置）を動かします。← → の行き先の決め方は §5 にあります。

- キーの押しっぱなしによる自動リピート（`e.repeat`）は、クリップの移動と止まりの移動では無視します。一回押すと一つ進みます。Shift + ← → のシークはリピートを受けます。
- Ctrl、Alt、Meta が付いたキーは扱いません。ブラウザの操作を奪わないためです。
- フォーカスが入力欄（input, textarea, contenteditable）にあるときは、キーを扱いません。

## 5. 再生のモデル

- **時計**: 再生中は、フレームごとに t を進めます。音声を鳴らしていない間は `t += min(dt, 0.1)` です（dt は rAF の時刻の差、秒）。音声を鳴らしている間は、§5.2 の決まりで声と合わせます。タブが隠れている間は時計も音声も止め、戻ったら再生を続けます。
- **時間割**: クリップの長さ `duration` と、文、印、止まりの時刻は、クリップに入るときに計算します（§6.7）。歩調（§5.1）が変わったら計算し直します。原稿を持たないクリップは、`clip.duration` をそのまま使います。この文書でクリップの duration と言うときは、どちらの場合もこの長さを指します。
- **クリップに入る**: ↑ ↓、目次、番号のキーで移ったときは、t = 0 から再生します。
- **次の止まりへ（→）**: いまの時刻 t より 0.05 秒以上あとにある最初の止まりを行き先にします。行き先が `pace.skip` 秒より遠ければ、`pace.skip` 秒だけ進めます。あとに止まりがなければ、クリップの終わりへ移ります。すでに終わりにいるとき（ended）は、次のクリップへ t = 0 で入ります。
- **前の止まりへ（←）**: t + 0.05 秒以前で最も近い止まりを「いまの止まり」とします。t がいまの止まりから `pace.again` 秒を超えていれば、いまの止まりへ戻ります。超えていなければ、一つ前の止まりへ戻ります。行き先が `pace.skip` 秒より遠ければ、`pace.skip` 秒だけ戻します。いまの止まりが時刻 0 で、一つ前へ戻るときは、前のクリップへ入り、その終わりの絵で止めます（ended）。
- **移ったあとの状態**: 止まりへの移動は、再生の状態を保ちます。再生中なら移った先から再生を続け、一時停止中なら止まったままです。一時停止のまま ← → を押すと、止まりを一枚ずつめくれます。ended から ← で戻ったときは、移った先から再生します。
- **着地の間**: 再生中に → か ← で静止点へちょうど移ったときは、`pace.land` 秒だけ時計を止めてから再生を続けます。その間 `.mx` に `data-landing` を付けます。待っている間に操作があれば、待つのをやめてその操作に従います。文の頭へ移ったとき、秒で送ったとき、クリップの終わりへ移ったとき（そのまま ended になる）は待ちません。
- **終わり**: t が duration に達したら t = duration にして、`data-state="ended"` にします。最後の絵（`render(duration)`）で止まります。
- **自動で次へ**: `data-auto` のとき、再生して終わりに達してから `clip.hold` 秒（既定は `pace.end`）後に次へ進みます。最後のクリップでは進みません。待っている間に何か操作があれば、待つのをやめます。移動やシークで終わりに着いたときは、待ち始めません。
- **シーク**: t を [0, duration] に収めて描き直します。再生中なら、その位置から再生を続けます。シークバーや Shift + ← → で ended から戻したときは paused にします。
- **描き直す時**: 再生中の各フレーム、シーク、リサイズ、クリップの入れ替え、フォントの読み込みの完了、時間割の計算し直し。止まっている間は rAF を回しません。
- **開いた直後**: フォントの読み込みを待って（§6.4）、URL の `?c=` のクリップ（なければ最初）を t = 0 から再生します。声のある文を持つクリップで、音声が入で、ブラウザが音を止めている場合だけ、再生を始めずに操作を待ちます（§5.2）。

### 5.1 歩調

歩調は、どのクリップにも効く時間の変数の組です。既定値は `src/explorer/pace.js` にあり、`deck.pace`（§7）が同じ形の一部を上書きします。調整用のパネル（§8.1）は、開いている間だけ値を書き換えます。

| 名前 | 既定 | 意味 | 読む側 |
|---|---|---|---|
| `voice.speed.slow` / `voice.speed.normal` / `voice.speed.fast` | 1.1 / 1.3 / 1.5 | 話速。ゆっくり、基本、早口の三段で、文が名前で選ぶ（§6.6）。語りの記録（§7.1）のどの録りを使うかが、これで決まる | engine |
| `voice.cps` | 6.3 | まだ合成していない文の長さを見積もるときの、話速 1 での 1 秒あたりの字数 | engine |
| `pre` | 0.3 | 声の前。文の絵が出てから声が始まるまで | engine |
| `rest.short` / `rest.normal` / `rest.long` | 0.3 / 0.8 / 1.0 | 文の間。声と動きが終わってから次の文が始まるまで。文が名前で選ぶ | engine |
| `land` | 1.0 | 着地の間 | engine |
| `skip` | 5 | 送りの幅。止まりへ跳ぶか、秒で送るかの境でもある | engine |
| `again` | 1.0 | ← を押したとき、いまの止まりへ戻るか、一つ前へ戻るかの境 | engine |
| `end` | 2.5 | 終わりの間。自動で次へ進むまで | engine |
| `enter` | 0.5 | 入り。一つの要素が出る時間 | クリップ |
| `stagger` | 0.08 | ずらし。並んだ要素の入りの時間差 | クリップ |
| `ground` | 1.0 | 文の頭で、地の要素を出し切るまでの上限 | クリップ |
| `cue.lead` | 0.15 | 強調の先回り。印の時刻より先に強調を始める | クリップ |
| `cue.rise` / `cue.fall` | 0.25 / 0.4 | 強調が立ち上がる時間、引く時間 | クリップ |
| `cue.scale` | 1.06 | 強調で持ち上げる倍率 | クリップ |
| `cue.dim` | 0.4 | 強調の間、ほかの要素を薄くしたときの不透明度 | クリップ |
| `cue.stay` | `'next'` | 強調の残し方。`'next'` は次の強調まで残し、`'phrase'` は `cue.span` 秒で引く | クリップ |
| `cue.span` | 1.2 | `cue.stay` が `'phrase'` のときの、強調の長さ | クリップ |

`voice.speed`、`cue.scale`、`cue.dim`、`cue.stay` を除いて、単位はすべて秒です。「読む側」が engine の変数は時間割と操作を決めます。クリップの変数は、クリップが `stage.pace`（§6.2）から読みます。

### 5.2 語りの音声

- 音声は既定で入です。`?sound=0` で開いたときと、M キーか `.mx-sound` で切ったときは切です。静止フレームのモード（§8）では、音声をいっさい扱いません。
- 文 i の音声は、時間割の `voice_i` から `end_i` まで鳴らします（§6.7）。再生中にその区間へ入ったら頭から、シークや移動で区間の途中へ入ったら途中から鳴らします。途中から鳴らすときは、0.02 秒かけて音量を上げます。一時停止、シーク、移動、クリップの入れ替えでは、鳴っている音声をすぐ止めます。
- 音声が鳴っている間は、画面に描いた時刻 t と、音声の再生位置から求めた時刻との差を 0.05 秒以内に保ちます。文の音声を鳴らし始めてから 0.1 秒より後のフレームが対象です。フレームが遅れたときも、差をためません。そのために、時計を音声の側に合わせてかまいません。
- ブラウザが音を止めているとき（利用者が操作するまでは音を出せない）は、声のある文を持つクリップの再生を始めません。`data-state` を `paused`、`data-sound` を `blocked` にして、ステージに `.mx-unlock`（§3.3）を出します。クリック、タップ、キー操作のどれかがあれば、音声を有効にして再生を始めます。その操作が M キーなら、音声を切にして無音で再生を始めます。声のある文を持たないクリップは、待たずに再生します。
- 音声のファイルがない、読み込めない、復号できないときは、その文を無音で再生します。復号した長さが語りの記録の `duration` と 0.05 秒以上違うときも、同じ扱いにします。時間割は語りの記録の長さのまま変えません。`console.warn` には一度だけ出します。
- クリップに入るときは、そのクリップの音声を読み込んで復号します。最初の文の音声を最長 3 秒待ち、間に合わなければ無音で始めて、読めた文から鳴らします。隣のクリップの分は先回りして読み込みます。復号した音声を持っておくのは、現在と前後のクリップの分までです。

## 6. クリップの契約

```js
export default {
  id: 'shannon',                     // デッキの中で一意。URL に使う（英小文字、数字、ハイフン）
  title: '次の文字を当てる',          // 題名（rail の見出し、目次、document.title）
  kicker: '1948 · Claude Shannon',   // 任意。題名に添える一行
  script: [                          // 語りの原稿（§6.6）。あれば duration と cues は書かない
    { id: 'a', text: '1948 年、シャノンは{prob}**次の文字の確率**で英文を作った。', still: true },
  ],
  duration: 14,                      // 秒。原稿を持たないクリップだけが書く。動きが終わる時刻
  cues: [                            // 字幕。原稿を持たないクリップだけが書く。at 秒から to 秒まで出す
    { at: 0.8, to: 5.5, text: '1948 年、シャノンは**次の文字の確率**で英文を作った。' },
  ],
  marks: [{ at: 6, label: '二次近似' }],                  // 任意。原稿を持たないクリップの止まり（§6.8）
  cast: ['metan', 'zunda'],          // 任意。立ち絵を出す語り手（§3.4）。既定は、原稿の中で話す語り手
  hold: 2.5,                         // 任意。自動で次へ進むまで、止まっている秒数（既定は pace.end）
  poster: 14,                        // 任意。目次の縮小図に描く時刻（既定は duration）。'a.end' のような名前でもよい
  numbered: true,                    // 任意。false なら章の中の番号を振らない（扉など）
  fonts: [['600 64px "IBM Plex Sans JP"', '描く文字列']], // 任意。最初に描く前に読み込む
  setup(stage) {
    // 一度だけ呼ばれる。DOM や canvas を作り、時刻によらない準備をする
    const { ctx } = stage.canvas();
    return {
      render(t) { /* 時刻 t の絵を描く。t の純粋関数にする */ },
      dispose() { /* 任意。後片付け。層の DOM は engine が消す */ },
    };
  },
};
```

### 6.1 時刻の純粋関数

- `render(t)` の結果は t だけで決まるようにします。前のフレームの状態に頼りません。だから、シークしても、`?t=` で開いても、目次の縮小図でも、同じ時刻なら同じ絵になります。
- 原稿を持つクリップは、時刻を数字で書かず、`stage.at(name)` と `stage.pace` から求めます（§6.2）。この二つは時間割と歩調が変わると値が変わるので、`render` の中で毎回読みます。同じ時間割、同じ歩調、同じ t なら、同じ絵になるようにします。
- 乱数は種付きの関数（`src/kit` の `hash`、`mulberry32`）を使い、`Math.random` は使いません。
- 時刻によらない計算（文字の幅の測定、スプライトの作成など）は setup で済ませてかまいません。

### 6.2 stage の API

| 名前 | 内容 |
|---|---|
| `stage.W`, `stage.H` | 1600, 900（論理座標） |
| `stage.el` | このクリップの層 `.mx-layer`。DOM で描くクリップは、この中に要素を置く。CSS の 1px が論理座標の 1 にあたる |
| `stage.canvas(opts)` | 層いっぱいの canvas を作り、`{ canvas, ctx }` を返す。`opts.alpha` の既定は true。描画バッファは 1600×900 に「拡縮の倍率 × devicePixelRatio」を掛けた大きさで、倍率は 2 まで、総画素は 420 万までに抑える。engine は `render` の直前に毎回 `ctx.setTransform(s, 0, 0, s, 0, 0)` を呼ぶので、クリップは論理座標のまま描ける。消去はしないので、クリップが背景から塗る |
| `stage.still` | 静止フレームのモードなら true |
| `stage.thumb` | 目次の縮小図のための setup なら true |
| `stage.theme(name)` | テーマの CSS 変数の値を文字列で返す。例: `stage.theme('--mx-accent')` |
| `stage.at(name)` | 時間割の時刻（秒）を返す。`name` は文の id か印の名前（§6.7）。知らない名前なら例外を投げる。原稿を持たないクリップでは使えない |
| `stage.duration` | クリップの長さ（秒）。時間割が変わると値も変わる |
| `stage.pace` | いまの歩調（§5.1）。`stage.pace.enter` のように読む。値は調整用のパネルで変わることがある |

DOM で描くクリップのために、engine は `render` の直前に、層へ `--mx-t`（秒）と `--mx-p`（0〜1）を書きます。CSS の `calc()` で、時刻に応じた見た目を書けます。

### 6.3 字幕の書き方

- 一つの cue は 2 行まで、1 行は全角 34 字ほどまでにします。
- `**…**` で強調します（テーマのアクセント色）。`\n` で改行します。
- cue は時刻の順に並べ、なるべく重ねません。重なったときは、両方を `at` の順に出します。
- 最後の cue の `to` を `duration` より後ろにすると、終わりで止まっている間も、その字幕が出たままになります。

### 6.4 フォント

- 枠の文字は DOM なので、必要な字はブラウザが読み込みます。
- canvas に描く文字は、最初に描く前に読み込んでおく必要があります。`deck.fonts` と `clip.fonts` に `[font, text]` を並べると、engine は `document.fonts.load(font, text)` をすべて待ってから描きます。日本語の書体は unicode-range で分かれているので、実際に描く文字列を渡します。
- `deck.fonts` は起動時に一度だけ待ちます。`clip.fonts` は、そのクリップを最初に描く前に待ちます。隣のクリップの分は先回りして読み込みます。

### 6.5 失敗したとき

- setup や render が例外を投げたら、その層にエラーの札（クリップの id と例外の文）を出し、そのクリップの render はそれ以上呼びません。console.error には一度だけ出します。ナビゲーションはそのまま使えます。

### 6.6 語りの原稿

語りのあるクリップは、`duration` と `cues` の代わりに `script` を書きます。`script` は文を順に並べたもので、字幕、読み上げ、時間割、止まりのすべてのもとになります。

```js
script: [
  { id: 'a', still: true,
    text: '最初の手がかりは{y48} 1948 年。\nけれど出来事の多くは、{band}**最後の 10 年**に集まっている。' },
  { id: 'b', lead: 2.0, label: '2017 年から',
    text: '{tf}2017 年の Transformer から、{gpt}GPT、{chat}[ChatGPT|チャットジーピーティー] へと一気に進んだ。' },
  { id: 'spin', lead: 3.0 },          // 声のない文。動きだけを見せる
],
```

| 項目 | 内容 |
|---|---|
| `id` | クリップの中で一意。英小文字で始め、英小文字、数字、ハイフンを使う |
| `text` | 文。字幕と読み上げのもとになる。省くと、声のない文になる |
| `label` | 任意。シークバーの目印に付ける短い名前。省くと、字幕の文の頭 12 字を使う |
| `by` | 任意。この文を話す語り手の id（§7.2）。既定は、配役の最初の語り手。声のない文では、値を確かめるだけで、使わない |
| `speed` | 任意。この文を話す速さ。`'slow'` / `'normal'` / `'fast'`。既定は `'normal'`。実際の話速は歩調の `voice.speed` が決める（§5.1）。声のない文では、値を確かめるだけで、使わない |
| `lead` | 任意、秒。声の前に見せる動き（軸の拡大など）の長さ。既定は 0 |
| `tail` | 任意、秒。声が終わったあとも続く動きの長さ。既定は 0 |
| `rest` | 任意。次の文までの間。`'short'` / `'normal'` / `'long'` か、秒の数。既定は、`still` の文なら `'long'`、ほかは `'normal'` |
| `still` | 任意。true なら、この文の声と動きが終わった時刻を静止点にする。最後の文は、書かなくても静止点になる |

`text` の中では、次の書き方が使えます。

| 書き方 | 字幕 | 読み上げ |
|---|---|---|
| `{name}` | 出ない | 出ない。声がここへ来る時刻に、印 `name` を置く |
| `[表記\|よみ]` | 表記 | よみ |
| `**…**` | 強調（`<strong>`） | 中の文をそのまま読む |
| `\n` | 改行 | 読まない |
| `\{` `\[` `\*` `\\` | その文字 | その文字 |

- 印の名前の規則は `id` と同じです。文の id と印の名前は、クリップの中で重ならないようにします。重なっていたら、そのクリップはエラーにします（§6.5）。
- 字幕の文は、`text` から印を取り除き、`[表記|よみ]` を表記に替えたものです。そのあとの扱いは cue と同じです（§3.4）。一つの文は 2 行まで、1 行は全角 35 字までにします。
- 読み上げの文は、`text` から印、`**`、改行を取り除き、`[表記|よみ]` をよみに替えたものです。さらに、半角の空白のうち、隣の字のどちらかが ASCII でないものを取り除きます（「1948 年」は「1948年」になり、英語の語の間の空白は残ります）。
- 動きを途中で待たせたいときは、文を二つに分けます。声の途中に間を入れる書き方はありません。
- 話す速さも、文ごとに一つです。文の途中で速さを変えたいときは、文を二つに分けます。`speed` に、三つの名前のほかの値や数を書いたら、そのクリップはエラーにします（§6.5）。

### 6.7 時間割

engine は、原稿と、声の長さと、歩調（§5.1）から時間割を計算します。文を順に i = 0, 1, … とし、文 i の声の長さを `A_i`（声のない文は 0）と書きます。

```
start_0     = 0
voice_i     = start_i + lead_i + (声のある文なら pace.pre、声のない文なら 0)
end_i       = voice_i + A_i
done_i      = end_i + tail_i
start_(i+1) = done_i + rest_i
duration    = done_(最後の文)
印の時刻     = voice_i + (声の頭から印までの秒数)
```

- `rest_i` は、名前なら `pace.rest` の値、数ならその秒数です。最後の文の `rest` は使いません。
- 文の話速は、`pace.voice.speed` のうち、その文の `speed` が指す値です（書いていなければ `normal`）。
- 声の長さと印の位置は、語りの記録（§7.1）のうち、話速がその文の話速に最も近い録りから取ります。同じ近さの録りが二つあれば、遅い方を使います。録りに位置のない印は、字数の割合で補います。
- 記録のない文と、記録が原稿より古い文は、見積もります。長さは「読み上げの文の字数 ÷ `pace.voice.cps` ÷ その文の話速」、印の位置は、印より前の字数の割合で決めます。見積もった文は無音で再生します。
- duration が 90 秒を超えるクリップはエラーにします（§6.5）。
- 時刻はすべて 0.001 秒に丸めます。

クリップは、`stage.at(name)` で時間割の時刻を読みます。

| `name` | 返す時刻 |
|---|---|
| `'a'`、`'a.start'` | 文 a の頭（`start`）。`lead` の動きはここから始まる |
| `'a.voice'` | 文 a の声の始まり |
| `'a.end'` | 文 a の声の終わり |
| `'a.done'` | 文 a の声と動きの終わり（`end + tail`） |
| `'a.next'` | 次の文の頭。最後の文では duration |
| `'band'` | 印 `band` の時刻 |

声が鳴っている間の時刻は、こうして声が決めます。作る側が秒で決めるのは、声の外にある `lead`、`tail`、`rest` と、歩調だけです。

### 6.8 止まり

止まりは、← → で移る先です（§5）。engine が時間割から作ります。

原稿を持つクリップの止まり:

- すべての文の頭 `start_i`。種類は `line`。
- `still` の文と最後の文の `done_i`。種類は `still`（静止点）。
- 二つの止まりの時刻の差が 0.05 秒未満なら、一つにまとめて `still` にします。

原稿を持たないクリップの止まり:

- 時刻 0 と、`clip.marks` の各 `at`（`marks` がなければ各 cue の `at`）。種類は `line`。
- duration。種類は `still`。

止まりは `{ at, kind, line, label }` の形で、`line` は文の id（原稿を持たないクリップでは null）です。静止点は、絵がそのまま一枚の図版として読める時刻にだけ置きます。声は終わっていて、字幕にはその文が出ています。`lead` で始まる文の頭は、見逃すと意味が取れなくなる動きの頭でもあります。静止点から → を押すと、その動きの頭へ移ります。

## 7. デッキの契約

```js
export default {
  id: 'llm',
  title: 'LLM',                          // 短い名前（パンくずの根、document.title）
  subtitle: '次の一語から、エージェントまで', // 目次の見出し
  fonts: [/* §6.4 */],                   // 任意
  autoAdvance: false,                    // 任意。「自動で次へ」の初期値
  chapters: [
    { id: 'history', title: '歴史', clips: [opening, shannon /* … */] },
  ],
  decorate(root) {},                     // 任意。枠に飾りの DOM を足す（root は .mx）
  pace: { rest: { long: 2.4 } },         // 任意。歩調の既定値の一部を上書きする（§5.1）
  frame: { gutter: 120 },                // 任意。枠の右に足す余白の列の幅（§2）。0〜240 の整数、既定は 0
  voice: {                               // 任意。語りの音声（§7.1）と配役（§7.2）
    cast: { metan: { name: '四国めたん', speaker: '四国めたん', style: 'ノーマル', credit: 'VOICEVOX:四国めたん' } },
    manifest, url(file) {},
  },
  credits: ['…'],                        // 任意。rail に出す表記（§3.2）。配役の credit は自動で加わる
};
```

- 章の id とクリップの id は、それぞれデッキの中で一意にします。
- 番号: 章は 1 から数えます。章の中のクリップも 1 から数え、`numbered: false` のものは数えません。通し番号（corner）は、すべてのクリップを 1 から数えます。
- クリップは、`script` か `duration` のどちらかを必ず持ちます。両方あるクリップと、どちらもないクリップはエラーにします。
- ページは `createExplorer(host, deck, options)` で作ります。`options.url`（既定 true）を false にすると、URL を読みも書きもしません。戻り値は §8 の API です。

### 7.1 語りの音声

音声は制作のときに合成し、ファイルにして配ります。ブラウザの中では合成しません。デッキごとに `decks/<id>/voice/` に置きます。

```
decks/<id>/voice/manifest.json                     語りの記録。リポジトリに入れる
decks/<id>/voice/<clipId>/<lineId>@<speed>.opus    配る音声（Ogg Opus）。文と話速ごとに一つ。リポジトリに入れる
decks/<id>/voice/<clipId>/<lineId>@<speed>.wav     合成した原本。リポジトリに入れない（.gitignore で除く）
```

配る形式は Ogg Opus です（mono、VBR 40 kbps）。Opus は、頭の遅れと末尾の詰め物の量をファイル自身が持っていて、復号すると原本と同じ長さに戻ります。だから、原本から求めた長さと印の時刻を、そのまま配る音声に使えます。MP3 は、この扱いがブラウザごとに違うので採りませんでした。Safari は macOS 15.4、iOS 18.4 より前では Ogg Opus を復号できません。その場合は、§5.2 のとおり無音で再生します。

`manifest.json` は、合成した結果の記録です。

```json
{
  "version": 2,
  "engine": { "name": "VOICEVOX", "version": "0.25.2" },
  "clips": {
    "timeline": {
      "a": {
        "by": "metan", "speaker": "四国めたん", "style": "ノーマル",
        "source": "最初の手がかりは1948年。けれど出来事の多くは、最後の10年に集まっている。",
        "reading": "サイショノ…",
        "takes": {
          "1.3": { "file": "timeline/a@1.3.opus", "duration": 5.419,
                   "anchors": { "y48": 0.896, "band": 3.893 },
                   "mouth": [[0, "x"], [0.085, "a"], [0.171, "i"], [0.288, "o"]],
                   "sha256": "…",
                   "master": { "file": "timeline/a@1.3.wav", "sha256": "…" } }
        }
      }
    }
  }
}
```

- `by`、`speaker`、`style` は、合成したときの語り手（§7.2）です。いまの原稿と配役から決まる語り手と違えば、その文の記録は古いものとして扱います。
- `source` は、合成したときの読み上げの文（§6.6）です。いまの原稿から作った読み上げの文と違えば、その文の記録は古いものとして扱います（§6.7）。
- `reading` は、エンジンが返した読み（カナ）です。読み違いを人が確かめるために残します。
- `takes` は録りの一覧で、キーは話速です。`file` と `sha256` は配る音声（Ogg Opus）のもの、`master` は合成した原本（WAV）のものです。`duration` は音声の長さ（秒）、`anchors` は音声の頭から各印までの秒数で、どちらも原本から求めます。
- `mouth` は口の動きです（§3.4）。`[秒, 形]` の並びで、音声の頭から数えてその秒に、その形になります。最初の項目は 0 秒です。印と同じく、エンジンが返す拍ごとの長さから求めます。母音の区間はその母音の形（無声化した母音も同じ）、「ん」は `n`、促音、間、音声の前後の無音は `x` です。子音の区間は、唇を閉じる子音（m、b、p と、その拗音）なら `x`、ほかの子音ならその拍の母音の形にします。同じ形が続く所は、一つにまとめます。
- 版 1 の記録（語り手が一人で、`mouth` がない）は、道具が次に書き込むときに版 2 に書き換えます。道具は、`mouth` のない録りを古い録りとして扱い、合成し直します。engine は、`by` のない記録を、配役の最初の語り手の録りとして読みます。`by` があって、いまの文の語り手と違う記録は、古いものとして扱います（§6.7）。
- 道具は、このほかに自分のための項目を書きます。録りの `generationSha256` は、読み上げの文、印、合成の設定をまとめたハッシュで、印だけを変えたときも古い録りと見分けるために使います。`_retired` は、作り直したり片づけたりして、使わなくなった録りの控えです。`_pending` は、書き込みの途中で止まったときに続きから直すための控えです。engine は、この三つを読みません。
- `deck.voice.url(file)` は、`takes` の `file` から音声の URL を返します。その作業環境にファイルがなければ undefined を返し、engine はその文を無音で再生します（§5.2）。デッキでは次のように書けます。

```js
import manifest from './voice/manifest.json';
const files = import.meta.glob('./voice/**/*.opus', { eager: true, query: '?url', import: 'default' });
export const voice = {
  cast: { metan: { name: '四国めたん', speaker: '四国めたん', style: 'ノーマル', credit: 'VOICEVOX:四国めたん' } },
  manifest, url: (file) => files[`./voice/${file}`],
};
```

音声を作る道具は `tools/narrate.mjs` です。

```bash
npm run narrate -- <deck> [clipId …]                              # 原稿と記録を比べて、足りない録り、古い録り、使っていない録りを一覧する
npm run narrate -- <deck> [clipId …] --generate [--speeds 1.2,1.3,1.4]   # 足りない録りと古い録りだけを合成し、配る音声を作る
npm run narrate -- <deck> [clipId …] --encode                     # 手元にある原本から、配る音声だけを作り直す
npm run narrate -- <deck> [clipId …] --prune                      # 使っていない録りを片づける
npm run narrate -- <deck> <clipId> --inspect                      # 合成せずに、拍ごとの高さと長さを見る
```

- 既定では何も起動せず、何も書きません。この機械にある VOICEVOX Engine を一時起動するのは、`--generate`（合成する）と `--inspect`（合成の手前まで）を付けたときだけで、終わったら止めます。エンジンは 127.0.0.1 の 8083 番で待ち受けます。起動と停止の作法、資源の上限は、道具の先頭に書きます。
- 配る音声は、原本から `opusenc` で作ります。同じ原本からは、いつも同じファイルができるようにします。作ったあと `opusdec` で復号し、長さが原本とサンプルの単位で一致することを確かめます（48 kHz で数えて、原本のサンプル数のちょうど 2 倍）。一致しなければエラーにして、その録りを記録しません。
- `--encode` は、エンジンを起動しません。原本があって配る音声がない録り、配る音声が記録と違う録りだけを作り直します。原本のない録りは、そのまま残します。
- 原本がなくても、配る音声と記録がそろっていれば、その録りは足りています。新しく取り出した作業環境では、合成し直さずに再生できます。
- `--speeds` を省くと、文ごとに、デッキの歩調でその文が使う話速（§6.7）の録りだけを合成します。基本の速さの文は `voice.speed.normal`、`speed: 'slow'` の文は `voice.speed.slow` の録りになります。
- `--speeds` を付けると、文の `speed` によらず、挙げた話速の録りをすべての文について合成します。歩調を決める前の聞き比べに使います。
- 使っていない録りは、話速が、その文がデッキの歩調で使う話速と違う録りです。聞き比べのために作った録りや、歩調を変える前の録りがこれにあたります。一覧には出しますが、合成や `--encode` では消しません。
- `--prune` は、使っていない録りを片づけます。配る音声を消し、記録を `takes` から `_retired` に移します。原本は消しません。エンジンは起動しません。配る音声はビルドがそのまま公開版に入れるので、歩調が決まったら片づけます。`--speeds` とは一緒に使えません。原稿から消えた文と、声のなくなった文の録りは、片づけの対象にしません。
- 道具が受け付ける話速は 0.5 から 2 までです。
- `--inspect` は、エンジンを一時起動して、合成の手前までを行います。文ごとに、読み（カナ）と、アクセント句ごとの拍の列（拍、高さ、子音と母音の長さ）、下がり目の位置を出力します。語彙（§7.3）を当てたあとの値です。音声は合成せず、何も書きません。音を聞けない場面で、抑揚と長さを数字で確かめるために使います。
- 印の位置は、エンジンが返す拍ごとの長さから求めます。印より前の読み上げの文の読みが、文全体の読みの頭と一致しないときは、エラーにしてその文を合成しません（印を句の切れ目へ動かすか、`[表記|よみ]` で読みを固定して直します）。
- 合成した音声の長さが、拍の長さの合計と 0.02 秒以上違うときも、エラーにします。
- 合成のあと、文ごとの読み（カナ）を出力します。数字、英語、記号の読みを確かめるためです。

### 7.2 配役と立ち絵

`voice.cast` は、語り手を id で並べたものです。文は `by` で語り手を選び（§6.6）、道具はその語り手の声で合成します（§7.1）。立ち絵を持つ語り手は、字幕の帯の端に出ます（§3.4）。

```js
voice: {
  cast: {
    metan: { name: '四国めたん', speaker: '四国めたん', style: 'ノーマル', credit: 'VOICEVOX:四国めたん',
             side: 'left', figure: metanFigure },
    zunda: { name: 'ずんだもん', speaker: 'ずんだもん', style: 'ノーマル', credit: 'VOICEVOX:ずんだもん',
             side: 'right', figure: zundaFigure },
  },
  manifest, url(file) {},
},
```

| 項目 | 内容 |
|---|---|
| id（キー） | 文の `by` と `clip.cast` が指す名前。規則は文の id と同じ |
| `name` | 語り手の名前。立ち絵の `aria-label` になる |
| `speaker`、`style` | 合成に使う VOICEVOX の話者とスタイル |
| `credit` | 任意。rail に出す表記（§3.2） |
| `side` | 立ち絵を出す側。`'left'` か `'right'`。`figure` があるときは必ず書く |
| `figure` | 任意。立ち絵。なければ、声だけの語り手になる |

- 並びの最初の語り手が、`by` のない文を話します。
- `voice` を持たないデッキでも、原稿のあるクリップは動きます。どの文も見積もった長さで無音になり、語り手も立ち絵もありません。そのデッキで文に `by` を書いたら、エラーにします。
- 0.4 までの、`voice` に `speaker` と `style` を直接書く形は使えません。語り手が一人でも `cast` に書きます。

立ち絵は、同じ大きさの画像を重ねて作ります。

```js
const metanFigure = {
  width: 336, height: 336,                 // 画像の画素数。どの画像も同じ大きさで、位置がそろっている
  base: url('base.png'),                   // 体と顔。目と口を別に持つなら、それを抜いたもの
  eyes: { open: url('eyes-open.png'), closed: url('eyes-closed.png') },   // 任意。なければ、まばたきしない
  mouth: { x: url('mouth-x.png'), a: url('mouth-a.png'), i: …, u: …, e: …, o: …, n: … },
};
```

- `mouth.x`（閉じた口）と `mouth.a` は必ず持ちます。ほかの形は任意で、なければ近い形で代えます（§3.4）。
- 画像は、出す範囲（上半身など）に切り抜いたものを用意します。engine は、切り抜きや位置合わせをしません。
- 絵の作者の表記や、素材の規約が求める表記は、`deck.credits` に書きます。

### 7.3 語彙

`voice.lexicon` は、読みやアクセントを決めておきたい語の表です。原稿には語をそのまま書き、読みと抑揚はこの表で一度だけ決めます。合成の道具だけが読み、engine は読みません。

```js
voice: {
  cast, manifest, url,
  lexicon: [
    { word: 'ChatGPT', kana: 'チャットジーピーティー', accent: 'flat' },
    { word: 'ツール', kana: 'ツール', accent: 'flat', long: 1.3 },
  ],
},
```

| 項目 | 内容 |
|---|---|
| `word` | 読み上げの文（§6.6）に出てくる形。同じ `word` を二度書いたらエラー |
| `kana` | 読み。カタカナで書く。長音は「ー」でよい |
| `accent` | `'flat'`（平板。語の中に下がり目がない）か、下がり目の直前の拍の番号（1 なら頭高）。番号は拍の数まで |
| `long` | 任意。長音（ー）の拍を伸ばす倍率。1 より大きく、3 以下。`kana` の中のすべての「ー」に効く |
| `type` | 任意。`'proper'`（固有名詞、既定）か `'common'`（普通名詞） |
| `priority` | 任意。エンジンの辞書の優先度。1〜9、既定は 5。語が文の中で効かないときに上げる |

- `accent` は、上がる位置ではなく、下がる位置の指定です。低く始めて途中で上げ、あとを高いまま保ちたい語は、`'flat'` にします。
- 道具は、エンジンを起動するたびに、前に自分が登録した語をエンジンのユーザー辞書から消してから、この表を登録します。道具のエンジンは辞書をプロジェクトの中（`.cache/voicevox/`）に持つので、この機械のほかの VOICEVOX の辞書には触れないはずです。それでも、辞書に道具が登録した覚えのない語が一つでもあれば、何も消さず、何も登録せずに、エラーにします。ほかの辞書を誤って書き換えないためです。
- アクセントは辞書で決まり、助詞が続いたときの句の形はエンジンが決めます。`long` は辞書では指定できないので、道具が、エンジンの返した拍の列の中からその語の拍を探し、長音の拍の母音の長さに倍率を掛けます。見つかった数が、読み上げの文に出てくる `word` の数と合わなければ、エラーにしてその文を合成しません。印の時刻と口の動きは、長さを変えたあとの値から求めます。
- 読みだけを一か所で変えたいときは、これまでどおり原稿に `[表記|よみ]` を書きます。`[表記|よみ]` で書き換えた所には、語彙は効きません（読み上げの文に `word` が残らないため）。
- 録りのハッシュ（§7.1 の `generationSha256`）には、その文の読み上げの文に出てくる語彙の項目を含めます。語彙を変えると、その語を含む文の録りだけが古くなります。

## 8. URL と確認用の契約

| パラメータ | 意味 |
|---|---|
| `?c=<clipId>` | そのクリップから開く。移動するたびに `history.replaceState` で書き換える |
| `&t=<秒>` | 静止フレームのモード。そのクリップの t 秒を、再生せずに表示する。層、題名、字幕の入れ替えの演出はしない |
| `&clean` | 枠を消し、ステージだけを画面いっぱいに出す（カバー画像などの撮影用） |
| `&auto=1` | 「自動で次へ」を有効にして開く |
| `&sound=0` | 音声を切にして開く |
| `&cast=0` | 立ち絵を出さずに開く |
| `&tune` | 調整用のパネル（§8.1）を出して開く |

静止フレームのモードでは、window に次のものを置きます。

- `window.__ready`: 最初の絵を描き終えたら true
- `window.__setTime(s)`: 同じクリップの s 秒を描き直す。枠の表示（シークバー、字幕、時刻）も合わせる
- `window.__go(clipId, s)`: 別のクリップの s 秒へ移る。描き終えたら解決する Promise を返す

トップページ（`src/home/`）は、デッキの表紙をこのモードで出します。デッキのページを `?c=<表紙のクリップ>&t=<その長さ>&clean` で iframe の中に開き、カードを指している間は親のページから `__setTime` を毎フレーム呼んで表紙のクリップを再生します。このモードの契約を変えるときは、トップページも合わせて直します。

どのモードでも、`window.__mx` に engine の API を置きます。

- 移動と再生: `go(clipId, { t })`, `next()`, `prev()`（クリップの移動）, `nextStop()`, `prevStop()`（止まりの移動、§5）, `play()`, `pause()`, `seek(t)`, `openIndex()`, `closeIndex()`。
- 語り: `setSound(on)`, `setSubs(on)`, `setCast(on)`（立ち絵を出すか）, `at(name)`（いまのクリップの時間割の時刻）。
- 歩調: `pace()`（いまの値の写し）, `setPace(patch)`（一部を書き換えて、時間割を計算し直す）。
- そのほか: `state()`, `on(event, fn)`, `destroy()`。

`state()` は `{ deck, chapter, clip, index, count, t, duration, state, auto, indexOpen, sound, subs, cast, line, stops, target }` を返します。`cast` は、いま出している立ち絵の並び `[{ id, side, speaking, mouth, eyes }]`（出していなければ空。目の画像を持たない立ち絵の `eyes` は null）、`line` は t を含む文の id（原稿を持たないクリップでは null）、`stops` はいまのクリップの止まり（§6.8）、`target` は → の行き先 `{ at, kind }`（クリップの中になければ null）です。イベントは `change`（クリップが変わった）、`state`（再生状態が変わった）、`time`（描いた）、`timeline`（時間割を計算し直した）です。

### 8.1 調整用のパネル

歩調（§5.1）を、動かしながら決めるための道具です。`&tune` で開いたときだけ読み込みます。

- `.mx` に `data-tune` を付け、`.mx` の直下に `<aside class="mx-tune">` を置きます。枠の拡縮の外にあり、ウィンドウの右端に固定します。畳むボタンを持ちます。パネルを開いている間は、枠をパネルの幅だけ狭い領域に収めて拡縮します。パネルがステージに重ならないようにするためです。
- §5.1 の変数を一つずつ並べます。数は range と number の入力、`cue.stay` と、`voice.speed` の三つ（`slow`、`normal`、`fast`）は select です。話速の選択肢は、いまのクリップのどれかの文の録りにある話速と、いまの値です。いまの値の録りがどの文にもないときは、その選択肢に「録りなし」と添えます。パネルが、鳴っている声と違う値を見せないようにするためです。録りが一つもないクリップでは選べません。項目の名前と範囲は、`src/explorer/pace.js` の `PACE_FIELDS` にあります。
- range と select は、ポインタで値を決めたらフォーカスを外します。Space や矢印キーを、すぐ再生の操作に戻すためです。
- 値を変えると `setPace` を呼びます。時間割が変わっても、見ている位置は保ちます。いまの t が属する文と区間（lead、声の前、声、tail、間）と、区間の頭からの秒数を覚え、新しい時間割の同じ位置へ移ります。区間が短くなって収まらないときは、区間の終わりへ移ります。
- いまの文の id、区間、t を表示します。
- いまの値を JSON で見せる欄と、既定に戻すボタンを持ちます。値は `localStorage`（キーは `mx-tune:<deck id>`）に保存し、`&tune` で開いたときだけ読み戻します。`&tune` を付けずに開いたときは、保存した値を使いません。保存するときは、そのときの既定値（`src/explorer/pace.js` に `deck.pace` を重ねたもの）も一緒に持ちます。読み戻すときに、いまの既定値がそれと違っていたら、保存した値を捨てます。既定値を決め直したあとに、古い調整が新しい既定値を隠さないようにするためです。

## 9. 資源の扱い

- 層は同時に 2 枚までです。速い連打で移動が重なったときは、最後の目的地だけを準備し、途中のクリップは setup しません。準備中だったものは捨てます。
- 題名のかたまりは 2 つまで、字幕の要素は 4 つまでです（出ていくものを含む）。
- 縮小図は、目次が開いている間だけ、1 フレームに 1 枚作ります。閉じたら作るのをやめます。
- rAF は、再生中と、描き直しが必要なときだけ回します。
- 音声の再生に使う `AudioContext` は、ページに一つだけ作ります。同時に鳴らす声は一つです。復号した音声を持っておくのは、現在と前後のクリップの分までです（§5.2）。音声の読み込みには 15 秒の上限を設け、超えたらその文を無音で再生します。一つの音声のファイルは 32 MiB までで、超えるものは読み込みません。

## 10. テーマの契約

テーマは CSS で、`.mx` の中の要素の見た目を自由に決めてかまいません。ただし次の二つは守ります。

- 四つの領域の位置と大きさ（§2）は変えません。
- 部品の DOM 構造（§3）に頼ってかまいません。engine はこの構造を版をまたいで保ち、変えるときは版を上げて §12 に書きます。

基本の CSS 変数。既定値は `src/explorer/explorer.css` にあり、テーマが上書きします。

| 変数 | 用途 |
|---|---|
| `--mx-bg` | 帯（レターボックス）と枠の地 |
| `--mx-stage-bg` | ステージの地 |
| `--mx-ink` | 枠の主な文字 |
| `--mx-muted` | 枠の控えめな文字 |
| `--mx-rule` | 罫線、シークバーの溝 |
| `--mx-accent` | 進み、強調、現在位置 |
| `--mx-on-accent` | アクセント色の上に載る文字 |
| `--mx-font` | 枠の書体 |
| `--mx-font-mono` | 時刻と番号の書体 |

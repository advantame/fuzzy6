### 事実と判定への含意

1. **初代 ChatGPT から追加学習がある（O1）。** GPT-3.5 系列から fine-tune し、人が利用者とアシスタントを演じた対話の教師あり学習と、複数応答の比較による報酬モデル、PPO を使った RLHF を説明している。「穴埋めを学んだだけの未調整モデルが、そのまま人向けに応答している」とは言えない。
2. **モデルと製品を分ける説明は支持できる（O2、O4）。** GPT-4 を ChatGPT と API から提供すると明記し、ChatGPT にブラウザや Python 実行等をつなぐ構成も公式発表されている。D2 の「中核にあるのが LLM」は妥当な要約。ただし「ChatGPT はモデルと呼ばれたことがない」は O1 に反する。追加学習はモデル自体を変更する工程であり、システム指示・画面・実行ツールと同じ種類の外付け部品ではない。
3. **指示は生成時の振る舞いにも関わる（O2 Steerability）。** system message でスタイルと課題を指定できる旨がある。2023-03 の記事だけで、現行 ChatGPT のすべての内部指示や経路まで確定したとはしない。
4. **「答えて、問題も解く」は能力の例として支持できる（O1、O3）。** O1 は対話・追加質問への応答を説明し、O3 は試験や言語課題の成績を報告する。一方、不正確な回答や推論誤りを明記している。D3 の「人みたいに」は会話の印象としてならよく、人間と同じ仕組み・理解・常に正答という意味を負わせない。
5. **GPT-4 には次トークン予測と追加学習の明示がある（O3）。** §2 は Transformer 型、次トークン予測の事前学習、RLHF の順を記す。これは Unit 3 の出発点。ただし同節は詳細な構造、モデル規模、計算、データ構成等を非公表と明記し、GPT-4 の記述だけで2026年の全モデルを説明することはできない。

### 事実と含意

1. **P1が直接測った中心は予測の交差エントロピー損失。** モデル規模・データ量・計算量を適切に増やすと改善する経験則であり、他の要因がボトルネックでない条件が付く。「どんな問題も、鍛える時間に比例して解ける」とは言わない。問題別の正答率にはP3の実測を使う。
2. **P2は大きさだけに資源を割く説明を修正する。** 同じ計算予算で、70BのChinchillaをより多くのトークンで訓練し、280BのGopherより広い評価群で良い成績を報告した。KaplanとHoffmannは、規模に伴う改善の方向は共有するが、最適なモデル／データ配分の推定は一致しない。二論文を同一の配分法則として紹介しない。
3. **P3は予測モデルの課題への広がりを支える。** 課題ごとの勾配更新やfine-tuningなしで、文章中の指示・例だけを与えて評価し、規模拡大で多くの課題が改善する一方、苦手な課題と汚染の懸念も報告する。Table 2.1では8規模とも300Bトークン、2048トークン文脈。学習率・バッチサイズなどは異なるため、「条件が大きさ以外すべて同一」は言えない。
4. **P4は追加学習の大きな効果を、限定された評価で示す。** 人の回答例による教師あり調整と、人の選好を利用したRLHFを行う。API由来の評価プロンプトでは、1.3BのInstructGPTの応答が175BのGPT-3より好まれた。これは指示追従・応答品質の証拠であり、全能力の何割がRLHF由来かという分解ではない。事前学習済みGPT-3にも、適切に問いかければ実行できる課題がある（p.4）。
5. **「知識や考えが言葉に入っている」は教育的な要約。** 文章には事実や手順・推論過程の記述がある、という意味では妥当。知識や思考がそっくり移植される機構の証明ではない。予測が様々な課題に役立つことを、データの性質と実測から説明する範囲にとどめる。

### 比較条件とD7への含意

1. **共通の事前学習の枠組みで8規模を比べたこと、課題別のfine-tuningをしていないことは言える（§2、Table 2.1）。** 全規模300Bトークン、文脈長2048。データ源はTable 2.2の共通構成だが、モデル幅・深さ・ヘッド構成・バッチサイズ・学習率等が異なる。「大きさだけが違い、他の条件は完全に同じ」「同一の文章列を同じ順番で学んだ」とは確定できない。計算量も規模とともに変わる。

6. **D7は「限定すれば言える」。** 知識問題、算術、文脈依存の語の予測で、概して大規模モデルがよい成績を取ったことは確かめられた。「筋を追う力」の厳密な意味と推理小説への対応はUnit 6で確定する。短い案の暫定形：「実際、続きを予測するように学んだモデルを比べると、大きいモデルほど、知識や計算、文脈を読む問題で、全体として正答率が高くなったの。」図または出典欄に「GPT-3、例を見せて評価、課題別の重み更新なし」を添える。

# 語りの音声について

このフォルダの音声（`.opus`）は、VOICEVOX で合成したものです。

- 表記: **VOICEVOX:四国めたん**、**VOICEVOX:ずんだもん**
- 話者とスタイル: 四国めたん（ノーマル）、ずんだもん（ノーマル）
- 合成に使ったもの: VOICEVOX Engine 0.25.2（CPU 版）。エンジン、モデル、辞書は、このリポジトリに含めていません。置いてあるのは、合成した音声と、その長さなどの記録（`manifest.json`）だけです。
- かかっている規約: [VOICEVOX 利用規約](https://voicevox.hiroshiba.jp/term/)、[四国めたんとずんだもんの音源利用規約](https://zunko.jp/con_ongen_kiyaku.html)（2026-10-11 に確認。ずんだもんの条件は 2026-10-13 に確認）

## 再利用について

作者は、この音声を取り出して別の用途に使うことを許諾しません（2026-10-11、ボスの決定）。リポジトリ全体の扱いは、ルートの [LICENSE](../../../LICENSE) にあります。

音声には、上の二つの規約の条件（クレジットの表示、制限されている用途）もかかっています。この文書は、それらの条件を変えるものではありません。

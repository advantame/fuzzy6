# 語りの音声について

このフォルダの音声（`.opus`）は、VOICEVOX で合成したものです。

- 表記: **VOICEVOX:四国めたん**
- 話者とスタイル: 四国めたん、ノーマル
- 合成に使ったもの: VOICEVOX Engine 0.25.2（CPU 版）。エンジン、モデル、辞書は、このリポジトリに含めていません。置いてあるのは、合成した音声と、その長さなどの記録（`manifest.json`）だけです。
- かかっている規約: [VOICEVOX 利用規約](https://voicevox.hiroshiba.jp/term/)、[四国めたんの音源利用規約](https://zunko.jp/con_ongen_kiyaku.html)（どちらも 2026-10-11 に確認）

## 再利用について

作者は、この音声を取り出して別の用途に使うことを許諾しません（2026-10-11、ボスの決定）。リポジトリ全体の扱いは、ルートの [LICENSE](../../../LICENSE) にあります。

音声には、上の二つの規約の条件（クレジットの表示、制限されている用途）もかかっています。この文書は、それらの条件を変えるものではありません。

## 公開の前に確かめたこと

- 2026-10-11: 1-1（`timeline`）の語りの 3 文が、音源の規約が制限する用途（政治や宗教の活動、特定の個人・団体・国家への非難や応援、情報商材、意図的な虚偽など）に当たらないことを、Claude が確かめた。中身は言語モデルの年表で、事実の出典は [../README.md](../README.md) の表にある。
- 2026-10-11: 合成した音声を公開リポジトリと GitHub Pages に置いてよい、とボスが判断した。規約の読み方と、判断の材料は [research/voice-terms/report.md](../../../research/voice-terms/report.md) にある。

語りを足すときは、足した文について同じ確認をして、ここに日付と一緒に書きます。

## 作り方

語りの原稿はクリップの `script` にあります。`npm run narrate -- llm <clipId> --generate` が、この機械の VOICEVOX Engine を一時起動して WAV を合成し、そこから配る音声（Ogg Opus）を作って、`manifest.json` に記録します。WAV はリポジトリに入れません。読みとアクセントを決めてある語は、[lexicon.js](lexicon.js) にあります。くわしくは [docs/spec.md](../../../docs/spec.md) の §7.1 にあります。

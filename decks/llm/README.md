# LLM — 次の一語から、エージェントまで

LLM を、歴史、基本概念、チャットボット、エージェントの順に見ていくデッキです（2026-10-10 着手）。説明を語るより、事実を見やすく並べることを優先します。いまは 4 章 26 本です。

`npm run dev` のあと http://127.0.0.1:5175/decks/llm/ で開きます。操作は ← → で前後のクリップ、Space で再生と一時停止、↑ で目次です（全体は `docs/spec.md` §4）。

## 狙い

- 字幕が事実の文を受け持ち、ステージが構造と数字を見せる。字幕の文をステージにそのまま書き写さない。
- 1 本のクリップには 1 つの考えだけを入れ、長さは 15〜17 秒にする。最後の絵（poster）が、そのまま一枚の図版として読めるようにする。
- 仕組みを示すために作った数値やモデルの出力には「例」の札を付ける。事実には出典を付け、ステージの右下に小さく書く。
- 実在するデータで見せられるものは実データを使う。トークンの分割と番号は、実際のトークナイザ（o200k_base）で求めた。

## 見た目の文法

- **地と色**: 枠は墨（#121110）、ステージは紙（#f4f1e9）に 40px 間隔の淡い点。朱（#ff5a1f）は合図に使う一色で、進み、強調、選ばれたものに使う。青は人や入力、緑は成功や確認、赤は誤りや拒否に使う。
- **L 字の二辺**: ステージの下の辺はクリップの進み、左の辺はデッキの中の位置として、朱で満ちていく（`theme.css`）。
- **書体**: 本文は IBM Plex Sans JP、大きな年と数字は IBM Plex Sans Condensed、トークン・コード・番号は IBM Plex Mono。
- **歴史の章の型**: 左の列に朱の札、年、人、論文または製品（`parts.js` の `yearBlock`）。右の列（x = 600 から）に中身を置く。
- **トークンの札**: 6 色の淡い色を順に使う。先頭の空白は小さな点で見せる。
- **rail の題名**: 本文の幅は 236px、42px なので、1 行に 5 字まで、2 行に収める。句の切れ目（`word-break: auto-phrase`）で折れるので、6 字以上の句を作らない。添え書きは 12 字ほどまで。
- **動き**: 入りは outExpo で 0.5〜0.8 秒、ずらしは 0.05〜0.15 秒。線は描き足し、数は数え上げる。最後の 3〜4 秒は読むために止める。

## 制作メモ

### 2026-10-10

- 画面は 1920×1080 の論理座標で、L 字は左 320、下 180。残るステージが 1600×900 で、画面と相似の 16:9 になる。1760×990 や 1600×900 のウィンドウでは全体を一様に縮める。
- トークンの例は、作業用の環境で js-tiktoken 1.0.21 の o200k_base を使って求めた。日本語の「かける」は「か｜け｜る」の 3 トークンになるので、2-4 の図は語の単位で描き、そう注記した。
- research の結果で直したもの: シャノンの原典表記、模倣ゲームの言い方（機械が人の役を演じても見破れるか）、ELIZA の逸話の出典（1976 年の回想）、Transformer の著者の所属と学会名（NIPS 2017）、王 − 男 + 女 の出典（ミコロフら）、ChatGPT の公開の形（研究プレビュー）、InstructGPT の比較の範囲、Mata v. Avianca の制裁の理由、ReAct と SWE-bench の言い方。
- 静止フレームでは枠のトランジションを止める（撮影の途中で軸が途切れて見えたため。`explorer.css` の `[data-still]` の規則）。
- 確認は `npm run capture -- llm --posters`（全クリップの最後の絵）と `npm run capture -- llm <id> --sheet --every 0.75`（動きの一覧）で行った。
- research が終わった（24 項目のうち確認 17、訂正 7。報告は `research/llm-facts/report.md`）。訂正はすべてクリップに反映してある。
- 4-5 horizon を足した。METR の値は版によって違う（2025 年 3 月の論文、その後に訂正した TH1.0、2026 年の TH1.1）。図では論文の点（黒）と TH1.1 の点（青の輪）を印で分け、二つを一本の線でつながない。7 か月の傾きは論文の値で、線の高さは図に出した論文の点の平均に合わせた。最初の成功率の曲線は、50% の位置（59 分）だけが論文の値で、形は模式図なので「例」の札を付けた。
- 再生中に字幕がまったく見えない不具合が見つかり、Astra が engine を直した（spec 0.2、codex の thread `01a121c4-6b6a-76d2-9dcb-af9cf7f6d671`）。撮影は静止フレームのモードで CSS のアニメーションを止めるので、それまでの確認では写らなかった。題名の入れ替えも、古い題名と新しい題名が重なって読めなかったので、古い方が消えてから新しい方を入れるようにした。
- A6（マルチエージェント）と A7（コンピュータ操作）の事実は、まだどのクリップにも出していない。下の候補のクリップで使う。

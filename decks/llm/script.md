# LLM の原稿

この文書は、各クリップの `script` から自動で作っています。手では直さず、クリップの `script` を直してください。dev サーバが動いている間は、クリップを直すたびに書き直されます。手で作り直すときは `npm run script -- llm` です。

話者を書いていない文は、四国めたんの文です。文の終わりの `a` などは文の id で、`compose/a` のように、クリップの id と合わせて指せます。

### 1-2 言語モデル `langmodel`（81.3 秒）

1. ここで言う「モデル」は、本物のふるまいをまねて、予測に使うものよ。 `a`

3. 言語モデルがまねるのは、言葉の並び方よ。 `c`
4. 言葉は、でたらめには並ばないわ。 `d`
5. 「のどがかわいたので、水を」と来たら、次は「飲んだ」がいちばんありそう。 `e`
6. 「買った」も、ありそう。「読んだ」は、まず来ない。 `e2`
7. 文法、言い回し、意味。いくつもの決まりが重なって、ありそうな言葉と、ありそうにない言葉が分かれるの。 `f`
8. この決まりの重なりが、言語の構造。言語モデルは、それをまねて、文章の穴に入る言葉を予測するのよ。 `g`
9. 予測は、一つに言い切らないわ。天気予報が「降水確率 70%」と言うのと同じ。 `h`
10. 手がかりになる言葉を見て、穴に入る候補のそれぞれに、ありそうな度合いを数字で付けるの。 `i`
11. この数字が、確率よ。 `i2`
12. 穴が、書きかけの文のすぐ先にあれば、それが「次の言葉の予測」になるわ。 `j`
13. **ずんだもん**　穴埋めは、わかったのだ。でも、ChatGPT は、人みたいに答えて、問題も解くのだ。 `q`
14. **ずんだもん**　あれと、この穴埋めが、つながっているのだ？ `q2`
15. つながっているわ。ChatGPT の LLM も、穴埋めを重ねて、答えの文を書いているの。 `k`
16. 言葉の並び方には、人の知識や考えが入っている。実際、穴埋めを鍛えたモデルは、多くの問題で成績を上げてきたの。 `k2`

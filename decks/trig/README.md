# 三角関数 — 直角三角形から、波の合成まで

直角三角形の辺の比から始めて、単位円、弧度法、グラフ（波）へ進み、加法定理と合成までを説明するデッキです（2026-10-15 着手）。数学の説明として独立したデッキで、LLM デッキとはつなげません。

いまは第 1 章（三角比）の 11 本が、語りつきでできています（2026-10-15、通して約 9 分）。2 章から先は、構成の段階です。いまの語りの原稿は、デッキの順に [script.md](script.md)（台本）にまとめてあります。台本は、各クリップの `script` から自動で作ります。下の「第 1 章の原稿」は、作る前に書いた稿の記録です。

`npm run dev` のあと http://127.0.0.1:5175/decks/trig/ で開きます。

## 狙い

- **見る人。** 中学数学（比、相似、三平方の定理、座標）までを知っている人。高校 1 年で初めて習う人と、学び直す大人の両方が、ほかの前提なしで追えるようにする。相似と三平方の定理は、使う所で短く思い出させる。
- **範囲。** 三角比から合成まで。数学 I の「図形と計量」と、数学 II の「三角関数」にあたる。一度にすべては作らず、章のまとまりごとに作る。
- **ずんだもんが話を進める。** ずんだもんが、何も知らないところから自分で考え、勢いで話を先へ進める。めたんは解説の係で、ずんだもんの見つけたことに名前を付け、足りないところを補い、まちがいを直す。デッキはずんだもん一人で始まり、めたんは、三角比を定義する所で割り込んで出てくる。
- **乱暴な問いから始める。** 道を歩いていたずんだもんが、木の高さを急に知りたくなる。ふだんの暮らしで木の高さを測ることはまずないが、その乱暴さで、かえって興味を引く。
- **角と一辺が決まれば、ほかの辺も決まる。** ずんだもんが方眼紙で見つけるこの見方を、デッキの芯にする。三角比は「角度で決まる倍率」として使い、単位円では「斜辺が 1 なら、高さも底辺も角度だけで決まる」として、三角関数につなげる。
- **三つの図を軸にする。** 直角三角形、単位円、波のグラフの三つ。同じ部品を同じ場所に描き、図から図へ、つないで移る。単位円の上の点の高さと、グラフの値のように、二つの図の対応する所は、同時に指す（[research/motion-principles/report.md](../../research/motion-principles/report.md) の勧め）。
- **公式は、図から導くところを見せる。** ただし、三角比の定義だけは、めたんが先に示して「頭に叩き込みなさい」と言い、演習で使いながら身につける。加法定理の重ねた三角形のように、作る順が説明になっている図は、順に描く。
- **例と値を分ける。** 作った場面と数（木までの距離、はしごの長さなど）には「例」の札を付ける。木の角度は 38° のように、きりの悪い値にする。三角比の値は計算した値なので札は付けず、小数第 4 位までにそろえる（語りでは、使う桁までに丸める）。

## 見た目と語りの方針

- **語り手。** 配役の最初は、ずんだもんにする（`by` のない文は、ずんだもんが話す）。ずんだもんの一人称は「ボク」で、語尾は「〜のだ」「〜なのだ」。考えたことをそのまま口にして、勢いで進める。めたんは常体で、語尾の「〜わ」「〜のよ」「〜なの」「〜かしら」は 1 文に一つまでとし、同じ語尾を続けない。ずんだもんには「〜しなさい」と言ってよい。立ち絵は、LLM デッキと同じ素材を、このデッキのために書き出す（リポジトリには入れない）。
- **話す速さ。** ずんだもんが勢いづく文（扉の終わり、1-1 の答え、1-3 の「め、めたん！？」と「いきなり暗記なのだ！？」）は早口（1.5）にした。ほかは基本の速さ（1.3）。言いよどむ所（「……」で始まる文）を、ゆっくり（1.1）にするかは、聞いて決める。
- **扉の茶番の絵。** 横から見た場面にする。ずんだもんの立ち絵を、ステージの上に小さく描き、茶番動画の定番どおり、歩くたびに上下に弾ませる。遠景（山並み、家並み、電柱、雲）は奥ほどゆっくり流す。この扉だけは、字幕の帯の立ち絵を出さず（`cast: []`）、ステージの上のずんだもんの口を、語りの記録の口の動き（字幕の帯の立ち絵と同じもの）で動かす（`lib/voice.js`）。まばたきもする。遠景が消えるときに、ずんだもんもステージから消え、1-1 から字幕の帯に移る。立ち絵の画像がない作業環境では、緑の小さな人形の形で代える。ステージの上に立ち絵を描くのは、このデッキで初めて。
- **めたんの登場。** 1-2 の終わり（「たてそこ比」）でクリップを切り、1-3 を、めたんの「待ちなさい！」から始める（`join: 'cut'`）。めたんの立ち絵は、1-3 から字幕の帯に出る。一つのクリップの途中で立ち絵を足す仕組みは、いまの engine にはないので、クリップの境目で登場させる。
- **三つの図の部品。** 直角三角形（`lib/tri.js`、1 章で作った）、単位円（`lib/circle.js`）、波のグラフ（`lib/graph.js`）を、それぞれ一つのモジュールにまとめる。LLM デッキの `lib/rig.js` と同じく、配置を関数にして、配置どうしの補間で動かす。三角形は、θ を左下、直角を右下に置く向きを基本にする（筆記体の覚え方が、この向きを前提にしているため）。5 章では、左に単位円、右にグラフを並べた配置を基本にする。
- **色。** 高さ（sin）は青、底辺（cos）は緑、tan は紫、斜辺と半径は墨にする。朱は、強調と答えの合図にだけ使う。名前が付く前の 1-1 から、縦の辺は青、底辺は緑で描き、5 章の波も同じ色で描く（sin の波は青、cos の波は緑）。
- **地。** 扉の遠景は、平らな色で塗った絵にする。遠景が消えると、薄い方眼の紙が残る。抽象化すると方眼紙になる、という見せ方で、1-1 の方眼紙にそのまま続く。2 章から先は、方眼が座標の目盛りになる。
- **式。** 式は字幕ではなく、図の中に組む（`lib/math.js`。上付き、分数、ルートを組める）。関数の名前（sin、cos、tan）とギリシャ文字（θ、α、β）は立体、ラテン文字（a、b）は斜体にする。IBM Plex Sans の斜体の θ は ϑ の形になり、教科書の θ と違って見えるため、ギリシャ文字は立てた。
- **筆記体の s、c、t。** 三角形の上に、一筆ずつ描く。先に通る辺に「1（分母）」、あとに通る辺に「2（分子）」の小さな番号を付ける。1-3 の最後の絵は、三つの式と三つの筆記体を一枚にまとめた「覚える表」にする。演習では、使う比の筆記体を、問題の三角形の上に番号なしで描き直し、その文が終わったら薄くする（図が筆の線で埋まらないように）。
- **字幕と記号。** 字幕には記号のまま書き、読みを付ける（`[sin θ|サインシータ]`、`[38°|38ど]`、`[√2|ルート2]`）。声で聞いた言葉と、図の記号が結びつくようにするため。
- **降り口（深掘り）の候補。** 1-9 から「サインという名前は？」（正弦の「弦」は円の弦のことで、弦の半分がサインになる）。1-4 から「表はだれが作った？」（6 章の加法定理を使って答える。1-4 では約束だけして本線で答えるか、深掘りにするかは、6 章を作るときに決める）。4-2 から「なぜラジアンを使う？」。

### 扉 測れない高さ（`opening`）

ずんだもん一人。立ち絵はステージの上に出す。

1. （声なし。道を歩いていく）
2. ……ん？　木があるのだ。
3. あの木の高さが、なぜか無性に知りたいのだ。
4. でも、登って測るのは無理なのだ。
5. わかるのは、木までの距離と、てっぺんを見上げる角度だけ……。
6. ……そうだ、数学を使えば、わかるはずなのだ！
7. 抽象化して、直角三角形について考えるのだ！

絵:

- 1（動き、`lead`）: 遠景が流れ、ずんだもんが弾みながら歩く。
- 2: 遠景が急に止まり、ずんだもんが少しつんのめって止まる。右から木がすべり込んでいて、ずんだもんの頭の上に「！」。
- 3: ずんだもんの目から木のてっぺんへ、見上げる破線。木の横に、高さの矢印と「？」。
- 4: 木の幹に沿って、登る道の点線が出て、朱の「×」が付く。
- 5: 「距離」の声で、ずんだもんの足もとから根もとまで、歩数の点が打たれていき、「18 m」が出る。「角度」の声で、分度器が見上げる線に当たり、「38°」が出る。「例」の札。
- 6: ずんだもんの頭の上に、電球のような印。
- 7（動き、`tail`）: 「抽象化」の声から、遠景、道の色、木の葉、ずんだもんが、ゆっくり薄れて消える。残るのは、地面の線（底辺、緑）、木の幹（縦の辺、青）、見上げる線（斜辺、墨）、直角の印、「18 m」「38°」「？」と、薄い方眼の紙。この最後の絵が、1-1 の頭の絵になる。トップページの表紙には、遠景が残っている時刻（6 の終わり）を使う（`poster`）。

### 1-1 小さく描く（`small`）

ずんだもん一人。扉からつなぐ（`join: 'cut'`）。

1. 木までの距離は 18 メートルで、見上げる角度は 38 度。知りたいのは、この縦の辺の長さなのだ。
2. 大きすぎて測れないなら、同じ形の、小さい三角形を描けばいいのだ。
3. 角度が同じなら、形も同じになる。中学でやった、相似なのだ。
4. 方眼紙に、底辺を 10 マスにして、38 度の角をはかって描くのだ。
5. 縦の辺のマスを数えると……だいたい 7.8 マスなのだ。
6. つまり、縦の辺は、底辺のだいたい 0.78 倍になっているのだ。
7. 形が同じなら、大きい三角形でも、縦の辺は底辺の 0.78 倍。木の高さは、18 メートルの 0.78 倍で……
8. だいたい 14 メートルなのだ！　登らずに、わかったのだ！

絵:

- 1（地）: 扉の最後の絵。頂点の名前 A, B, C（A は角をはかる所、B は木のてっぺん、C は直角）が、つないだ直後に出る。「18 m」「38°」「？」を、声に合わせて順に囲む。
- 2（動き）: 大きい三角形から、同じ形の小さい三角形が抜け出し、縮みながら右の方眼の上へ移る。角の弧の大きさは変えない。角度が変わらないことを、弧で見せる。
- 3: 二つの三角形の、同じ角に同じ印（弧を二重に）。「相似」の札。
- 4（動き）: 描く順に見せる。底辺を 1 マスずつ数えながら 10 マス引き、分度器を当てて 38° に印を付け、斜めの線を伸ばし、底辺の端から縦の線を立てる。頂点の名前 D, E, F は、その頂点を描いたときに出す。D は底辺を引き始める所、F は 10 マス目の端、E は斜めの線が上まで届いた所。D, E, F は A, B, C に対応する。
- 5: 縦の辺のマスを、下から 1 マスずつ数え上げる。最後のマスは 8 割ほどまでしか届かない。「約 7.8」。
- 6: 図の下に、分数で「EF/DF ＝ 7.8/10 ＝ 0.78」。E と F の名前の写しが図から分子へ、D と F の写しが分母へ飛んで、声が「縦の辺」「底辺」と言うところで着く。7.8/10 は分母が着いたところで、0.78 は声が言うところで出す。
- 7: 二つの三角形のあいだの空いた所に、「相似の性質」の枠。「△ABC ∽ △DEF ならば BC/AC ＝ EF/DF」。声の「形が同じなら」で出す。小さい三角形の 0.78 が、大きい三角形の式へ渡る。図の中に「18 × 0.78」。
- 8: 「？」が「約 14 m」に替わり、朱で光る。

### 1-3 三角比（`define`）

めたんが割り込んで出てくる。1-2 からつなぐ（`join: 'cut'`）。ここから二人。

1. めたん: 待ちなさい！　その比には、もう名前があるのよ。
2. め、めたん！？　いつからそこにいたのだ！？
3. めたん: 直角三角形の辺の比が、角度だけで決まる。そこまでは、あなたの見つけたとおりよ。
4. めたん: 角を θ として、θ が左下、直角が右下に来るように置くわ。
5. めたん: いちばん長い辺が斜辺、右の縦の辺が高さ、下の辺が底辺よ。
6. めたん: 高さを斜辺で割った比を、θ のサインと呼んで、sin θ と書くわ。
7. めたん: 底辺を斜辺で割った比は、コサイン。cos θ と書くの。
8. めたん: そして、高さを底辺で割った比が、タンジェント。tan θ と書くのよ。
9. ボクの「たてそこ比」は、タンジェントだったのだ……。
10. めたん: 覚え方を教えるわ。三角形の上に、筆記体の s、c、t を書くの。
11. めたん: sin の s は、斜辺を上ってから、高さを下りるわね。先に通る辺が分母、あとに通る辺が分子よ。
12. めたん: cos の c は、斜辺から底辺へ。tan の t は、底辺から高さへ進むの。
13. めたん: まずはこれを覚えて、頭に叩き込みなさい。
14. い、いきなり暗記なのだ！？
15. めたん: 使っているうちに、意味もわかってくるわ。さっそく、問題を解いてみましょう。

絵:

- 1: 「たてそこ比」の書き込みに、朱の線が一本引かれる。
- 2: 三角形と札が、驚いたように小さく跳ねる。
- 3: 1-2 の三枚の札（縦÷底辺、縦÷斜め、底辺÷斜め）が、三角形の横に並び直す。
- 4（動き）: 三角形が、θ が左下、直角が右下に来る向きにそろう。角に「θ」。
- 5: 「斜辺」「高さ」「底辺」の声で、辺の名前が出る（墨、青、緑）。札の「縦」「斜め」も、同じ名前に書き換わる。
- 6: 「高さ ÷ 斜辺」の札が、青の「sin θ ＝ 高さ／斜辺」に替わる。
- 7: 緑の「cos θ ＝ 底辺／斜辺」。
- 8: 紫の「tan θ ＝ 高さ／底辺」。
- 9: 「たてそこ比」の書き込みが、「tan」の札へ吸い込まれる。
- 10: 三角形が三つに複製され、横に並ぶ。
- 11（動き）: 左の三角形の上に、筆記体の s を一筆で描く。斜辺に「1」、高さに「2」。式の分母と分子が、同じ番号で光る。
- 12（動き）: 中の三角形に c、右の三角形に t を、同じように描く。
- 13: 三つの式と三つの筆記体が一枚の表にまとまり、朱の枠で囲まれる。これが最後の絵（目次の縮小図）。
- 14: 表を指したまま、何も足さない（ずんだもんの驚きの声だけ）。
- 15: 表が右上に小さく退き、左下に「演習」の札。

### 1-8 三つの比の関係（`relations`）

1. 三角比をいじっていたら、気づいたことがあるのだ。
2. sin θ を cos θ で割ると、斜辺どうしが消えて、高さ割る底辺……tan θ になるのだ！
3. めたん: そのとおり。tan θ は、sin θ と cos θ から求められるの。
4. それから、斜辺を 1 にすると、高さが sin θ、底辺が cos θ そのものになるのだ。
5. そこに三平方の定理を使うと……sin θ の 2 乗と、cos θ の 2 乗を足すと、1 になるのだ！
6. めたん: 式では、sin θ の 2 乗を、sin の右肩に 2 を書いて表すのが決まりよ。
7. 角度を変えて、確かめるのだ。……正方形の大きさは変わるけど、足すと、ずっと 1 なのだ！
8. めたん: では、sin θ が 0.6 のとき、cos θ と tan θ は、いくつかしら。
9. 0.6 の 2 乗は 0.36 だから、cos θ の 2 乗は 0.64 で、cos θ は 0.8 なのだ。
10. tan θ は、0.6 割る 0.8 で、0.75 なのだ！
11. めたん: 正解よ。一つの値がわかれば、残りの二つも、計算で求められるのよ。

絵:

- 1（地）: 三角形と、1-3 の三つの式（小さく）。
- 2（動き）: sin θ の式を cos θ の式で割る形に並べ、分母の「斜辺」が二つとも朱の線で消え、「高さ／底辺」が残って、tan θ の式に重なる。
- 3: 図の中に「tan θ ＝ sin θ ／ cos θ」。
- 4（動き、`lead`）: 三角形が縮み、斜辺に「1」。高さに「sin θ」、底辺に「cos θ」。
- 5: 「三平方」の声で、高さと底辺の上に正方形（青と緑の面）、斜辺の上に正方形（墨の線）。「1 になる」の声で、図の中に「sin²θ ＋ cos²θ ＝ 1」。
- 6: 式の「²」を囲み、横に小さく「sin²θ は (sin θ)² のこと」。
- 7（動き）: 角度がゆっくり開いたり閉じたりする。青の正方形が大きくなると、緑の正方形が小さくなる。二つの面積を一本の帯に並べた横の図は、長さ 1 のまま変わらない。
- 8: 問題の枠に「sin θ ＝ 0.6」。
- 9: 式が一行ずつ出る（0.6² ＝ 0.36、cos²θ ＝ 1 − 0.36 ＝ 0.64、cos θ ＝ 0.8）。
- 10: 「tan θ ＝ 0.6 ÷ 0.8 ＝ 0.75」。高さ 3、底辺 4、斜辺 5 の三角形を、斜辺 1 に縮めた図が添わる。
- 11: 三つの式（sin、cos、tan）を矢印で結ぶ。

### 1-9 もう一つの角（`complement`）

1. そういえば、三問めで三角形を置き直したとき、気になったことがあるのだ。
2. 直角三角形には、θ のほかに、もう一つ角があるのだ。
3. 三つの角を足すと 180 度だから、その角は、90 度ひく θ なのだ。
4. その角が左下に来るように置き直すと……高さと底辺が、入れ替わるのだ！
5. だから、90 度ひく θ のサインは、θ のコサインと同じなのだ。
6. めたん: よく見つけたわね。反対に、90 度ひく θ のコサインは、θ のサインと同じになるわ。
7. めたん: このように、足して 90 度になる二つの角を、互いの余角と呼ぶの。
8. コサインの「コ」という音も、もしかして、そこから来ているのだ？
9. めたん: ええ。コサインは、「余角のサイン」という意味の言葉を、縮めた名前なのよ。
10. めたん: 日本語でも、サインを正弦、コサインを余弦と呼ぶわ。
11. めたん: 余弦の「余」という字は、余角の「余」と同じなの。

絵:

- 1（地）: 斜辺 1 の三角形。左下の角に「θ」。
- 2: 上の角に弧と「？」。
- 3: 上の角に「90° − θ」。図の中に「θ ＋ (90° − θ) ＋ 90° ＝ 180°」。
- 4（動き）: 三角形が裏返り、90° − θ の角が左下に来る。高さと底辺の色が入れ替わる。
- 5: 図の中に「sin(90° − θ) ＝ cos θ」。
- 6: その下に「cos(90° − θ) ＝ sin θ」。
- 7: 二つの角の弧を同時に囲み、「余角」の札。
- 8: 「cos」の「co」を囲む。
- 9: 「cosine ＝ co ＋ sine」を、余角の札と線で結ぶ。
- 10: 「正弦」「余弦」の札を並べ、「余」を朱にする。

### 1-10 坂道の角度（`slope`、演習 4）

1. めたん: 最後の問題よ。坂道の標識に「10%」と書かれているのを、見たことはあるかしら。
2. めたん: これは、水平に 100 メートル進むと、10 メートル高くなる、という傾きを表しているわ。この坂の角度を求めなさい。
3. 高さと底辺だから、t の形なのだ。tan θ は、10 割る 100 で、0.1 なのだ。
4. あとは、tan が 0.1 になる角度を、表から探せばいいのだ。
5. tan 5° はおよそ 0.087、tan 6° はおよそ 0.105 だから……6 度近くなのだ。
6. ……え、10% なのに、6 度もないのだ？
7. めたん: そうよ。「10%」は角度ではなく、高さを水平の距離で割った比を、百分率で表した数なの。
8. めたん: 電卓には、比の値から角度を求める機能もあって、計算すると、およそ 5.7 度になるわ。
9. 角度から比も、比から角度も、求められるようになったのだ！
10. ……でも、直角三角形の角は、90 度より小さいのだ。もっと大きい角の sin は、どうなるのだ？

絵:

- 1（地）: 坂道の標識の絵（「10%」）。「例」の札。
- 2（動き）: 標識から坂道の断面へ移る。水平に 100 m の寸法線、高さに 10 m の寸法線。縦は引き伸ばさず、実際の傾きで描く。
- 3: 坂の上に筆記体の t を描き、図の中に「tan θ ＝ 10 ÷ 100 ＝ 0.1」。
- 4: 右に、表の tan の欄。0.1 を探す矢印が、上から下へ動く。
- 5: 表の 5° と 6° の行が光り、0.1 がそのあいだに入ることを示す。
- 6: 坂の角の小ささを囲む。
- 7: 「10%」と「θ」を並べ、それぞれが何の値かを札で添える（高さ ÷ 水平の距離 ／ 角度）。
- 8: 角に「約 5.7°」。
- 9: 「角度 → 比」と「比 → 角度」の二本の矢印。
- 10: 坂の三角形の角が、ゆっくり 90° を超えて開こうとして、三角形が作れずに止まる（「？」）。2 章の問い。

### 比と比の値（`ratio`）

1. 基礎概念の復習を始めるわ。最初は、小学校で習った、比と比の値。
2. さっきの方眼紙の三角形は、縦の辺が 7.8 マス、底辺が 10 マス。この二つを並べた 7.8 対 10 を、比というの。
3. 比は、両方に同じ数を掛けても、同じ数で割っても変わらない。7.8 対 10 は、78 対 100 とも、0.78 対 1 とも書けるのよ。
4. 後ろを 1 にしたときの前の数を、比の値と呼ぶ。a 対 b の比の値は、a を b で割った、b 分の a。
5. 7.8 対 10 の比の値は 0.78。縦の辺は、底辺の 0.78 倍ということ。さっき求めたのは、比の値だったのよ。
6. 比の値が同じなら、二つの比は等しい。a 対 b ＝ c 対 d は、b 分の a ＝ d 分の c と同じことなの。
7. ただし、前と後ろを入れ替えると、比の値は変わる。10 対 7.8 の比の値は、およそ 1.28。どちらを前に置くかで、意味が変わるわ。

絵:

- 1（地）: 方眼紙の左に、DEF（縦 7.8 マス、底辺 10 マスの寸法つき）。
- 2: 寸法の 7.8 と 10 が図から飛び、右に「7.8 : 10」。
- 3: その下に「78 : 100」「0.78 : 1」が並び、矢印に「× 10」と「× 1/10」。
- 4: 枠「比の値」に「a : b の比の値は a/b」。
- 5: 枠の下に「7.8/10 ＝ 0.78」。縦の辺と底辺を囲む。
- 6: 枠「等しい比」に「a : b ＝ c : d のとき a/b ＝ c/d」。
- 7: 「10 : 7.8」と、比の値「約 1.28」。7.8 : 10 の 0.78 と並べる。

### 相似な図形（`similar`）

1. 次は、中学で習った相似。一つの図形を拡大か縮小して、もう一つにぴったり重ねられるとき、二つの図形は相似というの。
2. 記号では、三角形 ABC 相似 三角形 DEF と書く。頂点は、対応するものどうしを同じ順に並べるわ。
3. 相似な図形では、対応する角はそれぞれ等しく、対応する辺の比はすべて等しい。
4. 三角形が相似になる条件は三つ。三組の辺の比がすべて等しい。二組の辺の比と、その間の角がそれぞれ等しい。二組の角がそれぞれ等しい。
5. さっきの二つの三角形は、38 度の角と直角が等しいから、三つめの条件で相似といえるのよ。
6. 相似の性質に出てくるのは、二つの三角形をまたぐ比。BC 対 EF ＝ AC 対 DF。
7. さっき使ったのは、一つの三角形の中の比。式を変形すると、こちらも成り立つことがわかるわ。
8. 形が同じなら、大きさが違っても、一つの三角形の中の辺の比は変わらない。これが、このあと何度も使う考え方なの。

絵:

- 1（動き）: DEF が拡大されながら動き、ABC にぴったり重なって、元の場所に戻る。
- 2: 「△ABC ∽ △DEF」。A と D、B と E、C と F を細い線で結ぶ。
- 3: 枠「相似な図形の性質」に「∠A ＝ ∠D、∠B ＝ ∠E、∠C ＝ ∠F」と「AB : DE ＝ BC : EF ＝ CA : FD」。
- 4: 三つの条件を、小さなカードで一枚ずつ。
- 5: 38° の弧と直角の印を、二つの三角形で同時に光らせる。三つめのカードを囲む。
- 6: 「BC : EF ＝ AC : DF」。二つの三角形をまたいで、対応する辺どうしを色でつなぐ。
- 7: 式を変形する二行（「BC/EF ＝ AC/DF」から「BC/AC ＝ EF/DF」へ。両辺に EF/AC を掛ける）。変形の中身は声では言わない。
- 8: 「BC/AC ＝ EF/DF」の枠を残し、二つの三角形の中で、縦の辺と底辺を同じ色で光らせる。

### 確かめる問題（`quiz`）

問題は三つ。選択肢を選んで答える（spec §5.4）。正解の返事と、不正解か飛ばしたときの返事を分け、そのあとの解説は同じにする。

1. 最後に、問題を三つ出すわ。選択肢から、答えを選んで。
2. 一問め。6 対 8 と等しい比は、どれかしら？（選択肢: 3 : 4（正解）、4 : 3、12 : 14）
   - 正解のとき: 正解。よくできたわ。
   - 不正解か飛ばしたとき: 答えは、3 対 4。
3. 6 と 8 を、どちらも 2 で割ると、3 対 4。比の値は、どちらも 0.75 なの。
4. 二問め。三角形 ABC と三角形 DEF が相似なとき、AC 分の BC と等しいのは、どれかしら？（選択肢: EF/DF（正解）、DF/EF、DE/DF）
   - 正解のとき: そのとおり。
   - 不正解か飛ばしたとき: 答えは、DF 分の EF。
5. 対応する頂点を、同じ順に読めばいいのよ。B と E、C と F、A と D。
6. 三問め。長さ 1 メートルの棒の影が 1.5 メートルのとき、影が 12 メートルの木の高さは、どれ？（選択肢: 8 m（正解）、18 m、10.5 m）
   - 正解のとき: 正解。
   - 不正解か飛ばしたとき: 答えは、8 メートル。
7. 日の光の向きは同じだから、棒と影の三角形と、木と影の三角形は相似。
8. 高さは、影の 1.5 分の 1 倍。12 メートルの 1.5 分の 1 で、8 メートルになるわ。
9. 復習は、これでおしまい。

選択肢のねらい:

- 一問め: 4 : 3 は前と後ろの入れ替え、12 : 14 は両方に同じ数（6）を足した誤り。
- 二問め: DF/EF は分母と分子の入れ替え、DE/DF は対応する辺の取り違え。
- 三問め: 18 m は 12 × 1.5（掛けるか割るかの取り違え）、10.5 m は 12 − 1.5。

絵:

- 1（地）: 札「問題」。
- 2: 「6 : 8」を大きく。選択肢は下に横一列。
- 3: 「6 : 8 ＝ 3 : 4」と、二つの比の値「6/8 ＝ 3/4 ＝ 0.75」。
- 4: 小さな二つの三角形 ABC と DEF（1-1 の向き）と、「BC/AC ＝ ？」。
- 5: B と E、C と F、A と D を結ぶ線。「BC/AC ＝ EF/DF」。
- 6: 棒と影、木と影の、二つの直角三角形。日の光の線は平行。「例」の札。
- 7: 二つの三角形の、光の角に同じ弧の印。
- 8: 「高さ/12 ＝ 1/1.5」から「高さ ＝ 8」。
- 9: 三つの問題の小さなまとめ（正解の数は数えない）。

## 読み

数字と記号の読みは、原稿に `[表記|よみ]` で書く。よみは、カタカナで書く。ひらがなで書くと、数の読みの中の「は」が助詞の「ワ」になる（0.78 の「れいてんななはち」が「レイテンナナワチ」）。和文と英数字・記号のあいだには空白を入れる（「だいたい [7.8|ナナテンハチ] マス」）。読み上げの文では、和文に接する空白は取り除かれる。

合成して読み（カナ）を見て、次を直した（2026-10-15）。

| 語 | 最初の読み | 直し方 |
|---|---|---|
| 「辺」（縦の辺、辺の比など） | アタリ | `[辺\|ヘン]`。斜辺、底辺、二辺は正しく読まれた |
| 数の読みの「は」（0.78、tan 38° など） | レイテンナナワチ、タンジェントサンジュウワチド | よみをカタカナで書く |
| 5 分の 3、4 分の 3、ルート 2 分の 1 | ゴフンノ、ヨンプンノ、ニフンノ（時間の「分」） | `[5 分の 3\|ゴブンノサン]` など |
| 角 θ（1-6 の最後） | スミ | `[角\|カク]` |
| 0.9397 | キュ・ウサン・キュウと切れる | `[0.9397\|レイテンキューサンキューナナ]` |
| 「コ」「余」のかぎ括弧 | 括弧の前後で途切れる（コ、モ） | 1-9 の言い回しを「「コ」という音も」に直し、かぎ括弧ごとよみに入れた（`[「コ」\|コ]`） |
| 「10%」のかぎ括弧 | 「ジュッパーセント、ト」と途切れる | `[「10%」\|ジュッパーセント]` |

確かめたかった語のうち、θ（シータ）、sin、cos、tan（サイン、コサイン、タンジェント）、筆記体の s、c、t（エス、スィー、ティー）、相似（ソージ）、方眼紙、三平方の定理、余角、正弦、余弦は、意図どおりに読まれた。語彙（`voice.lexicon`）には、まだ何も入れていない。アクセントと間（「……」「！？」の上げ方、「たてそこ比」の区切り）は、ボスが聞いて決める。

### 2026-10-15（式を TeX で組み、数字と文字を Computer Modern にする）

ボスの指示: 式、数字、アルファベットのフォントを、普通の数学のもの（LaTeX の字）に変える。式も、各要素を動かせるまま LaTeX で書けるようにできないか。

作ったもの:

- `src/kit/tex.js`（どのデッキでも使える）。TeX の文字列を MathJax 3.2.2（`mathjax-full`）で組み、出てきた字の輪郭（SVG のパス）を canvas に描く。字は MathJax の TeX フォント（Computer Modern）なので、Web フォントを読み込まずに本と同じ形になる。`\el{名前}{…}`（中身は MathJax の `\cssId`）で囲んだ部分は、置かれた箱、基線、大きさを返す。描くときに、その部分だけを薄くする、色を変える、ずらす、拡大縮小する（`o.parts.名前` に `{ alpha, color, dx, dy, scale }`）。組版は TeX の文字列だけで決まり、文字列ごとに一度だけ組んで覚えておく。そのため、部分を一つずつ出していく式でも、ほかの部分の位置は動かない。
- 式の中の日本語（`\text{高さ}`）は、MathJax が字の大きさを測れない。全角 0.9 em の字として場所を取らせ、その場所に IBM Plex Sans JP で描く。Plex の仮名と漢字は全角なので、幅はぴったり合う。
- `lib/math.js` は、これまでの書き方（`row`、`frac`、`jp`、`tag`、`shade` など）のまま、中で TeX に直して `src/kit/tex.js` で描く。TeX をそのまま書くときは ``tex(String.raw`…`)``。例: ``math(ctx, tex(String.raw`\frac{\el{num}{BC}}{AC} = \frac{EF}{DF}`), x, y, { size: 44 })``。色、太さ、`shade` の濃さは TeX の文字列に入れず、名前を付けた部分ごとに描くときに渡す。こうすると、値が毎コマ変わっても組み直さない。
- 決まり: 関数名（sin、cos、tan）と数字は立体、文字（θ、x）と点の名前（A、BC）は斜体、単位（m）は立体。分数は別行立て（display）の大きさで組み、分数の中の分数も外と同じ大きさにした（`\dfrac`）。TeX の既定では中の分数が小さくなり、1-8 の繁分数が読めなかった。相似の記号は `\backsim`（∽）。
- 図の札も、数字や文字を含むものは TeX で組む（「38°」「18 m」「約 7.8 マス」、頂点の名前）。日本語だけの札（「高さ」「斜めの辺」）はこれまでどおり太字の Plex で描く。数字と日本語が混じる札では、日本語を中くらいの太さ（500）にした。数字（Computer Modern の普通の太さ）と並べると、太字の日本語が浮いて見えた。
- canvas に `fillText` で描く文字（表の数字、目盛りの数字、注の中の数字）は、KaTeX のフォント（`katex` 0.16.11 の KaTeX_Main と KaTeX_Math、Computer Modern の写し）にした。`lib/theme.js` の字体の並びを、KaTeX_Main、IBM Plex Sans JP の順にしたので、一つの文字列の中で、数字と英字は KaTeX から、仮名と漢字は Plex から取られる。道路標識の「10%」と、ずんだもんの頭の「！」「？」は、式ではないので Plex のままにした。
- 1-1 の名前の写しは、図の名前も式の字も同じ TeX の斜体になった。そのため、飛ぶ間は大きさと色だけが変わる。
- 1-8 の二行めの位置は、一行めの式の高さから決めるようにした（分数が高くなって、手で決めた位置では重なった）。1-10 の「θ ＝ 角度」は、10% の式の右に移した（下に置くと坂の線に近すぎた）。

測ったこと: trig デッキの JS は MathJax の分だけ増え、約 1.9 MB になった。式の組版は文字列ごとに一度で、二度めからは覚えた結果を使う。

直したついでに見つけたもの: MathJax は、一つの字や記号を `\cssId` で二重に囲むと、外側の id で内側の id を上書きする。1-9 の「余弦」の「余」は、名前（強調の枠のため）と太さ（式の中の日本語の太さ）の二つの id を持っていて、太さが消え、細く描かれていた。いまは、名前の付いた部分の中の太さや色を、その名前の部分にまとめて持たせる。二つの名前が重なるときは、内側を TeX の組（`{…}`）にして、どちらの id も残す。`tests/math-tex.test.js` が、どの名前も MathJax を通ったあとに残ることを確かめる。

確認: unit 1,457 件（`tests/tex.test.js` の 5 件と `tests/math-tex.test.js` の 3 件を足した）、e2e 118 件（三か所のつなぎの画素の一致を含む）、build が通った。全 11 本の止まりごとの絵を、変える前と見比べた。1-1 の名前が飛ぶところと、0.78 が木の式へ渡るところを見た。

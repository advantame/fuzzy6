# 語りの音声について

このフォルダの音声（`.opus`）は、VOICEVOX で合成したものです。

- 表記: **VOICEVOX:四国めたん**、**VOICEVOX:ずんだもん**
- 話者とスタイル: 四国めたん（ノーマル）、ずんだもん（ノーマル）
- 合成に使ったもの: VOICEVOX Engine 0.25.2（CPU 版）。エンジン、モデル、辞書は、このリポジトリに含めていません。置いてあるのは、合成した音声と、その長さなどの記録（`manifest.json`）だけです。
- かかっている規約: [VOICEVOX 利用規約](https://voicevox.hiroshiba.jp/term/)、[四国めたんとずんだもんの音源利用規約](https://zunko.jp/con_ongen_kiyaku.html)

## 作り方

語りの原稿はクリップの `script` にあります。`npm run narrate -- anglesum <clipId> --generate` が、この機械の VOICEVOX Engine を一時起動して WAV を合成し、そこから配る音声（Ogg Opus）を作って、`manifest.json` に記録します。WAV はリポジトリに入れません。読みとアクセントを決めてある語は、[lexicon.js](lexicon.js) にあります。くわしくは [docs/spec.md](../../../docs/spec.md) の §7.1 にあります。

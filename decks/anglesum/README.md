### 1-1 長さと単位円（`norm`）

1. め: 舞台は、実数の組の平面 R² よ。二つのベクトルの内積を、成分どうしの積の和で定めるわ。
2. め: ベクトルの長さは、自分自身との内積の平方根。成分で書くと、三平方の定理と同じ形になるの。
3. め: 原点からの長さが 1 の点を、すべて集める。この集合を、単位円 S¹ と呼ぶわ。
4. め: 0 でないベクトルを、その長さで割る。向きはそのままで、長さが 1 になるの。
5. ず: 原点から描けば、その先端は、単位円の上の一点になるのだ。
6. め: 長さが違っても、向きが同じベクトルは、同じ点に移る。向きが違えば、違う点に移るわ。
7. め: だから、ベクトルの向きは、単位円の上の点で表せる。角度は、この円の上で測るのよ。

絵:

- 1（地）: 座標軸と方眼。原点から x と y。式 ⟨x, y⟩ ＝ x₁y₁ ＋ x₂y₂。x₁、x₂ を、x の横と縦の成分の線分で示し、式の文字と同じ色にする。
- 2: x と成分の線分で直角三角形。式 |x| ＝ √⟨x, x⟩ ＝ √(x₁² ＋ x₂²)。
- 3: 単位円。式 S¹ ＝ {(x, y) ∈ R² | x² ＋ y² ＝ 1}。円の上の数点に、長さ 1 の線分。
- 4（動き）: 式 x/|x|。x が、原点からの半直線に沿って縮み、単位円に乗る。長さの数値が 1 になる。
- 5: 先端の点が光る。
- 6: 同じ半直線の上の、長さの違う三本が同じ点へ、別の向きの一本が別の点へ移る。
- 7: 単位円の上の二点（二つの向き）を残す。

### 1-2 弧の長さ（`arc`）

1. め: 単位円の弧の長さを定めるわ。弧を、パラメータ s で動く点 γ(s) が通る曲線として表すの。
2. め: 曲線の長さは、速度ベクトルの長さを、s について端から端まで積分した値よ。
3. め: 同じ弧を、折れ線で近似してみるわ。分点を増やしていくと、折れ線の長さは、この積分の値に近づくの。
4. め: 単位円の一周の長さを、2π と書く。これが、π の定義よ。
5. め: 座標軸についての折り返しは、弧の長さを変えない。だから単位円は、長さの等しい四つの弧に分かれるわ。
6. め: 半周の長さは π、四分の一周の長さは π/2 になるの。

絵:

- 1（地）: 単位円の上の弧 PQ。弧の上を動く点 γ(s)。
- 2: 何点かの速度ベクトル γ′(s)。式 L ＝ ∫ |γ′(s)| ds。
- 3（別の図）: 弧に内接する折れ線（分点 4、8、16、32）。それぞれの長さの数値が、弧の長さの数値に近づく。
- 4: 一周を描き、「2π」。式「π ＝ （S¹ の一周の長さ）/ 2」。
- 5（動き）: x 軸と y 軸についての折り返しで、四つの弧が重なる。
- 6: 上半円に「π」、第 1 象限の弧に「π/2」。

### 1-3 角の大きさ（`angle`）

1. め: 単位円の上を、(1, 0) から反時計回りに、長さ s だけ進んだ点を、E(s) と書くわ。
2. め: s が 2π 増えると、ちょうど一周して、同じ点に戻る。E(s ＋ 2π) ＝ E(s) よ。
3. ず: 数直線の上で 2π ずつ離れた s は、どれも、単位円の同じ点に移るのだ。
4. め: 点 a から点 b まで、単位円を反時計回りに進む弧の長さを、a から b への回転角と呼ぶわ。0 以上、2π 未満の数よ。
5. め: 二つのベクトルのなす角は、二つの向きの点を結ぶ、短い方の弧の長さ。0 から π までの数になるの。
6. め: a から b への回転角を θ とすると、なす角は、θ と 2π − θ の小さい方よ。
7. め: 三角形の内角 α は、B − A と C − A のなす角。β と γ も、頂点から出る二つの辺のベクトルで定めるわ。

絵:

- 1（地）: 単位円と E(0) ＝ (1, 0)。点が反時計回りに s だけ進み、弧に長さ s。下に s の数直線と、その上の点 s。
- 2: 数直線の s − 2π、s、s ＋ 2π から、単位円の同じ点 E(s) へ線。式 E(s ＋ 2π) ＝ E(s)。
- 3: 2π おきの点が、同じ色で光る。
- 4: 単位円の上の a と b。a から b への反時計回りの弧（矢じり付き）と、長さ θ。式 0 ≤ θ ＜ 2π。
- 5: 短い方の弧を塗り、長い方を破線にする。
- 6（動き）: 式「なす角 ＝ min(θ, 2π − θ)」。b を動かし、θ が π を超えたところで、塗る弧が反対側に替わる。
- 7: 三角形 ABC。A を中心とする単位円（縮尺どおり）の上に、B − A と C − A の向きの点と、そのあいだの短い弧（α）。β、γ も薄く。

### 1-4 回転（`rotate`）

1. め: 原点を中心とする回転は、内積を保つ線形写像のうち、裏返しを含まないものよ。
2. め: 内積を保つから、回転は単位円を単位円に移す。速度ベクトルの長さも保つから、弧の長さも変えないわ。
3. め: 裏返しを含まないから、反時計回りの弧は、反時計回りの弧に移る。
4. め: だから、回転は、単位円のどの点も、反時計回りに同じ長さだけ進める。その長さ θ を、回転の回転角と呼ぶの。
5. め: 式で書くと、R(E(s)) ＝ E(s ＋ θ)。回転角 θ₁ の回転のあとに θ₂ の回転をすると、E(s) は E(s ＋ θ₁ ＋ θ₂) に移るわ。
6. ず: 回転角は、足し算になるのだ。でも、E(s ＋ 2π) は、E(s) と同じ点なのだ。
7. め: そう。合わせた回転の回転角は、θ₁ ＋ θ₂ から 2π の整数倍を引いて、0 以上 2π 未満にしたものになるの。
8. め: 回転角は 2π を法として足される、というのは、このことよ。

絵:

- 1（地）: 単位円と、原点から出る二本のベクトル。回転で二本がそろって回り、長さとなす角の数値は変わらない。
- 2: 単位円の上の弧と、その像の弧。速度ベクトルも一緒に回り、長さが同じ。二つの弧の長さの数値が等しい。
- 3: 弧の矢じりが、像でも反時計回り。
- 4: いくつかの点 E(s) から R(E(s)) へ、どれも長さ θ の弧。
- 5: 式。単位円の上で θ₁ と θ₂ の弧がつながる。下の数直線で、s から s ＋ θ₁、s ＋ θ₁ ＋ θ₂ へ進む。
- 6（別の図）: 数直線の s ＋ θ₁ ＋ θ₂ と、そこから 2π 引いた点が、単位円の同じ点に線でつながる。
- 7: 式 (θ₁ ＋ θ₂) − 2π と、その値の点。
- 8: 式の枠「回転角は 2π を法として足される」。

### 2-1 辺ベクトル（`edges`）

1. め: 証明 1 を始めるわ。A、B、C を、反時計回りに並ぶ、一直線上にない三点とするの。
2. め: 辺ベクトルを、u ＝ B − A、v ＝ C − B、w ＝ A − C と定める。
3. め: 三つを足すと、A、B、C がそれぞれ、プラスとマイナスで一回ずつ出て、打ち消しあう。u ＋ v ＋ w ＝ 0 よ。
4. ず: 図では、u の終点から v が、v の終点から w が出て、A に戻ってくるのだ。
5. め: 三つを原点から描き直して、長さで割る。三つの向きは、単位円の上の三点になるわ。
6. め: この証明では、この三点のあいだの弧を調べていくの。

絵:

- 1（地）: 三点 A、B、C。三角形の内側に、反時計回りの矢じり付きの弧。
- 2: 辺の上に矢印 u、v、w と、三つの式。
- 3: (B − A) ＋ (C − B) ＋ (A − C) の項を色分けし、打ち消しあう項に線を引く。式 u ＋ v ＋ w ＝ 0。
- 4: u、v、w の矢印が順に光り、A に戻る。
- 5（動き）: 三本の矢印が平行移動で原点に集まり、長さで割られて、単位円の上の三点 u/|u|、v/|v|、w/|w| になる。
- 6: 三点のあいだの三つの弧を薄く描く。

### 2-2 行列式（`det`）

1. め: 二つのベクトル x、y の行列式を、det(x, y) ＝ x₁y₂ − x₂y₁ と定めるわ。
2. め: その絶対値は、x と y が張る平行四辺形の面積に等しいの。
3. め: 符号を見るために、x が x 軸の正の向きになるように、全体を回転する。回転では、行列式の値は変わらないわ。
4. め: 回転したあとは x ＝ (|x|, 0) だから、行列式は、|x| と、y の第 2 成分の積になるの。
5. め: だから、y が x の向きの左側にあれば正、右側にあれば負よ。
6. ず: y を x の向きから反時計回りに回すと、半周までは正、そこから一周までは負なのだ。
7. め: x から y への回転角を θ とすると、回転したあとの y は |y| E(θ)。だから、det(x, y) ＝ |x||y| sin θ と書けるわ。

絵:

- 1（地）: 原点から x と y。式。成分の文字と、図の成分の線分を同じ色にする。
- 2: 平行四辺形を塗る。底辺 |x| と、高さ（y の先端から x の直線までの距離）の破線。式 |det(x, y)| ＝ 面積。
- 3（動き）: 図全体が回転し、x が x 軸の正の部分に乗る。行列式の数値は変わらない。
- 4: 回転したあとの y の第 2 成分の線分。式 det(x, y) ＝ |x| y₂。
- 5: x の直線の左側の半平面に「＋」、右側に「−」を淡く塗る。
- 6（動き、別の図）: y が一周し、右に、回転角に対する det の値のグラフが描かれていく。
- 7: 式 det(x, y) ＝ |x||y| sin θ と、注「sin θ は E(θ) の第 2 成分」。

### 2-3 三つの行列式（`equal`）

1. め: A、B、C が反時計回りに並ぶとは、C が、A から B への向きの左側にあること。det(B − A, C − A) ＞ 0 よ。
2. め: v ＝ C − B は、(C − A) − (B − A) と書けるわ。
3. め: 行列式は双線形で、同じベクトルを二つ入れると 0 になる。だから、det(u, v) は det(B − A, C − A) に等しく、正なの。
4. め: 次に、w ＝ −u − v を代入する。det(v, w) も det(w, u) も、展開すると det(u, v) だけが残るわ。
5. ず: 三つの行列式が等しいのは、図では、どう見えるのだ？
6. め: det(u, v) は、u と v を、どちらも B から描いて張った平行四辺形の面積。底辺は |u|、高さは C から直線 AB までの距離よ。
7. め: 三角形 ABC も、底辺 AB の長さが |u| で、高さが同じ。だから、平行四辺形の面積は、三角形の面積の 2 倍になるの。
8. め: C でも A でも、同じように平行四辺形を張ると、面積はどれも三角形の 2 倍。三つの行列式が等しいことと合っているわ。

絵:

- 1（地）: 三角形。直線 AB を延ばし、A から B への向きの左側の半平面を淡く塗る。C がその中にある。式 det(B − A, C − A) ＞ 0。
- 2: 式。図では、C − A と B − A の矢印から、v の矢印ができる。
- 3: 展開の式。det(B − A, B − A) ＝ 0 の項に線を引く。
- 4: 二行の展開。消える項に線を引く。
- 5: 三つの頂点に、平行四辺形の輪郭を薄く。
- 6: B から u と v を描いた平行四辺形を塗る。C から直線 AB への垂線（高さ）。
- 7（別の図）: 三角形 ABC を同じ底辺と高さで重ね、式「面積 ＝ |u| × 高さ ＝ 2 × △ABC」。
- 8: C と A の平行四辺形も塗る。三つに「2 × △ABC」。

### 2-4 回転角 θ（`turn`）

1. め: u から v、v から w、w から u への、反時計回りの回転角を、θ₁、θ₂、θ₃ とするわ。
2. め: 単位円の上では、θ₁ は、u の向きの点から v の向きの点まで、反時計回りに進む弧の長さよ。
3. め: 三角形の上では、θ₁ は、B で、u を延ばした向きから v の向きまでの角になるの。
4. め: det(u, v) ＝ |u||v| sin θ₁ で、行列式は正。だから sin θ₁ ＞ 0 で、θ₁ は 0 と π のあいだにあるわ。
5. め: θ₂ と θ₃ も同じ。0 ＜ θ₁, θ₂, θ₃ ＜ π よ。
6. ず: 単位円の上では、v の向きの点は、u の向きの点から半周より手前にあるのだ。ほかの二つも同じなのだ。

絵:

- 1（地）: 2-1 の単位円（u、v、w の向きの点）。反時計回りの弧 θ₁（緑）、θ₂（紫）、θ₃（青）が順に出る。
- 2: θ₁ の弧が光る。
- 3: 三角形の B に、u の延長（破線）と v、そのあいだの角 θ₁。B を中心とする単位円を同じ縮尺で重ね、2 の弧と同じであることを示す。
- 4: 2-2 の det のグラフで、θ₁ が正の側（0 から π）にある。式。
- 5: 式 0 ＜ θ₁, θ₂, θ₃ ＜ π。
- 6: u の向きの点から反時計回りに半周を淡く塗り、v の向きの点がその中にある。

### 2-5 回転角の和（`once`）

1. め: 回転角 θ₁ の回転は、u の向きを v の向きに移す。θ₂ の回転は v を w に、θ₃ の回転は w を u に移すわ。
2. め: 三つを順に合わせた回転は、u の向きを u の向きに戻す。単位円の点を一つ動かさない回転だから、回転角は 0 なの。
3. め: 回転角は 2π を法として足されるから、θ₁ ＋ θ₂ ＋ θ₃ は 2π の整数倍。整数 k を使って、2kπ と書けるわ。
4. ず: 単位円の上を見ているだけでは、k がいくつなのかは、わからないのだ。
5. め: そこで、回転角を数直線の上で足すの。u の向きを E(s₀) とすると、三つを順に足した先は、s₀ ＋ 2kπ のどれかよ。
6. め: 三つとも 0 と π のあいだだから、和は 0 と 3π のあいだ。その範囲にある 2π の整数倍は、2π だけなの。
7. ず: だから k ＝ 1。θ₁ ＋ θ₂ ＋ θ₃ ＝ 2π なのだ！

絵:

- 1（動き）: 単位円の上で、u の向きの点から θ₁、θ₂、θ₃ の弧を順にたどる。
- 2: u の向きの点に戻る。式「三つの回転を合わせた回転 ＝ 恒等写像」。
- 3: 式 θ₁ ＋ θ₂ ＋ θ₃ ＝ 2kπ。
- 4: 単位円の横に「k ＝ ？」。
- 5（別の図）: 下に s の数直線。s₀ から θ₁、θ₂、θ₃ の長さの区間を順に並べる。2π おきの点 s₀ ＋ 2πℤ を、単位円の u の向きの点と線で結ぶ。
- 6: s₀ から s₀ ＋ 3π までの開区間を塗る。中にある 2π おきの点は s₀ ＋ 2π だけ。s₀ と s₀ ＋ 4π に ×。
- 7: 三つの区間の終わりが s₀ ＋ 2π に着く。単位円の三つの弧が、すき間なく一周を埋める。式を枠で囲む。

### 2-6 内角（`interior`）

1. め: 最後に、内角とつなぐわ。A の内角 α は、u ＝ B − A と、C − A ＝ −w のなす角よ。
2. め: 単位円の上で、−w の向きの点は、w の向きの点から、反時計回りにちょうど半周進んだ点。
3. め: 0 ＜ θ₃ ＜ π だから、u の向きの点は、その半周の途中にある。w から u までが θ₃、u から −w までが π − θ₃ よ。
4. め: π − θ₃ は 0 と π のあいだだから、これが短い方の弧。α ＝ π − θ₃ になるの。
5. め: 同じように、β ＝ π − θ₁、γ ＝ π − θ₂ になるわ。
6. め: 足すと、α ＋ β ＋ γ ＝ 3π − (θ₁ ＋ θ₂ ＋ θ₃)。θ の和は 2π だから……
7. ず: 3π ひく 2π で、π なのだ！　証明 1 が、できたのだ！

絵:

- 1（地）: 三角形の A。u と −w（A から C）と、α の扇形（青）。
- 2: 単位円の上の w の向きの点と、半周先の −w の向きの点。半周の弧。
- 3: u の向きの点が、半周の途中にある。弧 θ₃（青の線）と、π − θ₃ の弧。
- 4: π − θ₃ の弧を青で塗る。三角形の A に同じ縮尺の単位円を重ね、α と同じであることを示す。
- 5: B と C の同じ図を小さく。
- 6: 式。
- 7: 「＝ 3π − 2π ＝ π」を枠で囲み、□。

### 3-1 座標の設定（`place`）

1. め: 証明 2 を始めるわ。平行移動と回転は、内積を変えないから、なす角も変えない。
2. め: だから、三角形を動かして、A を原点に、B を x 軸の正の部分に置いてよいの。
3. め: 回転は、反時計回りの並びも変えない。だから C は上半平面に来て、A ＝ (0, 0)、B ＝ (L, 0)、C ＝ (p, h)、L ＞ 0、h ＞ 0 と書けるわ。
4. め: p は、どんな実数でもいい。p ＜ 0 なら α が、p ＞ L なら β が、鈍角になるのよ。

絵:

- 1（地）: 証明 1 と同じ三角形。辺の長さと角の数値。
- 2（動き）: 三角形が平行移動し、回転して、A が原点、B が x 軸の正の部分に乗る。辺の長さと角の数値は変わらない。
- 3: 座標の札。L と h の寸法線、p の目盛り。
- 4（動き）: C が左右に動き、p ＜ 0 で α が、p ＞ L で β が鈍角になる。角の数値が変わる。最後は元の位置に戻る。

### 3-2 単位ベクトル q(t)（`ray`）

1. め: 実数 t に対して、点 (t, h) を考えるわ。t を動かすと、この点は、直線 y ＝ h の上を動くの。
2. め: このベクトルを長さで割った単位ベクトルを、q(t) とする。原点と (t, h) を結ぶ線分が、単位円と交わる点よ。
3. め: h ＞ 0 だから、q(t) の第 2 成分は正。q(t) は、単位円の上半分にあるわ。
4. め: t が増えると、q(t) は時計回りに動く。t → ∞ で (1, 0) に、t → −∞ で (−1, 0) に近づくの。
5. ず: でも、(1, 0) と (−1, 0) そのものには、着かないのだ。
6. め: そう。t と q(t) は、実数全体と、両端を除いた上半円とを、一対一に対応させているわ。

絵:

- 1（地）: 原点、単位円、直線 y ＝ h。直線の上の点 (t, h) が左右に動く。直線に t の目盛り。
- 2: 原点から (t, h) への線分と、単位円との交点 q(t)。式 q(t) ＝ (t, h)/√(t² ＋ h²)。
- 3: 上半円を淡く塗る。
- 4（動き）: t が増え、q(t) が時計回りに動き、通った跡が残る。
- 5: 両端 (±1, 0) に白丸。
- 6: t ＝ −3, …, 3 の目盛りと、それぞれの q(t) を線で結ぶ。

### 3-3 q の速さ（`speed`）

1. め: q(t) を t で微分するわ。
2. め: q(t) と q′(t) の内積を計算すると、0 になる。速度ベクトルは、単位円の接線の向きよ。
3. め: 長さを計算すると、速さは、h を t² ＋ h² で割った値になるの。
4. ず: 速さが、この形になるのは、どうしてなのだ？
5. め: 別の図で確かめるわ。点 (t, h) は、x 軸の向きに速さ 1 で動く。原点からの距離を r とすると、線分に垂直な成分の大きさは h/r よ。
6. め: 単位円の上では、原点からの距離が 1 だから、垂直な成分は 1/r 倍になる。速さは h/r²、つまり h/(t² ＋ h²) になるわ。
7. め: 速さは、t ＝ 0 で最大の 1/h をとり、t の絶対値が大きくなるにつれて 0 に近づくの。

絵:

- 1（地）: 式 q′(t) ＝ (h², −ht)/(t² ＋ h²)^{3/2}。
- 2: 単位円の上の q(t) に、速度ベクトル q′(t) を縮尺どおりに描く（接線の向き）。式 ⟨q(t), q′(t)⟩ ＝ 0。
- 3: 式 |q′(t)| ＝ h/(t² ＋ h²)。
- 4: 式の右に「？」。
- 5（別の図）: 点 P ＝ (t, h) に速度 (1, 0)。原点からの線分の向きと、それに垂直な向きに分ける。垂直な成分の長さ h/r を、直角三角形の相似（原点、(t, 0)、P の三角形）で示す。
- 6: 垂直な成分を、原点を中心に 1/r 倍に縮めて、単位円の上へ移す。長さ h/r² が、2 の q′(t) の長さと重なる。
- 7: 下に、速さのグラフ y ＝ h/(t² ＋ h²)。t ＝ 0 で 1/h、遠くで 0 に近づく。

### 3-4 角の積分表示（`integral`）

1. め: a ＜ b として、向き (a, h) と (b, h) のなす角 θ(a, b) を求めるわ。
2. め: 二つの向きの点は q(a) と q(b)。どちらも上半円にあって、そのあいだの上半円の弧は、長さが π より短いの。
3. め: だから、その弧が短い方の弧で、なす角は、その弧の長さよ。
4. め: t が a から b まで動くと、q(t) は、その弧を一方向に一度だけ通る。だから、弧の長さは、速さを a から b まで積分した値になるわ。
5. め: θ(a, b) は、a から b までの、h/(t² ＋ h²) の積分よ。
6. ず: なす角が、速さのグラフの、a から b までの面積に等しいのだ。
7. め: a や b が ±∞ のときは、極限の向き (−1, 0) や (1, 0) とのなす角になって、積分は広義積分になるの。

絵:

- 1（地）: 直線の上の (a, h) と (b, h)、原点からの二本の線分。
- 2: 単位円の上の q(a) と q(b)。上半円の中の弧を塗り、もう一方の弧は破線。
- 3: 塗った弧に「θ(a, b)」。
- 4（動き）: q(t) が弧を通る。下のグラフで、a から b の面積が左から塗られていく。
- 5: 式 θ(a, b) ＝ ∫ₐᵇ h/(t² ＋ h²) dt を枠で囲む。
- 6（別の図）: 弧と面積を同じ色で同時に光らせ、二つの数値（同じ値）を並べる。
- 7（動き）: b を ∞ へ動かす。弧が (1, 0) まで伸び、面積が右へ伸びる。

### 3-5 α（`alpha`）

1. め: A の角 α は、B − A ＝ (L, 0) と、C − A ＝ (p, h) のなす角よ。
2. め: (L, 0) の向きは (1, 0)。これは、t → ∞ での q(t) の極限の向き。(p, h) の向きは q(p) よ。
3. め: だから α ＝ θ(p, ∞)。p から ∞ までの広義積分になるの。
4. め: 被積分関数は、t を −t に替えても同じ値をとる偶関数。グラフは縦軸について対称よ。
5. め: t ＝ −s と置き換えると、p から ∞ までの積分は、−∞ から −p までの積分に等しくなるわ。
6. ず: 単位円の上では、α の弧を、y 軸について折り返した弧なのだ。長さは変わらないのだ。

絵:

- 1（地）: 3-1 の三角形。A の α（青の扇形）。(L, 0) と (p, h) の矢印。
- 2: 直線 y ＝ h の、C より右の部分。単位円の上で、q(p) から (1, 0) への弧。
- 3: 式 α ＝ ∫ₚ^∞ h/(t² ＋ h²) dt。グラフの [p, ∞) を青で塗る。
- 4: グラフの対称の軸（破線）。式 f(−t) ＝ f(t)。
- 5（動き）: 塗った面積が、縦軸について折り返されて (−∞, −p] へ移る。式 α ＝ ∫_{−∞}^{−p}。
- 6（動き、別の図）: 単位円の青い弧も、y 軸について折り返され、(−1, 0) から q(−p) までの弧になる。

### 3-6 β（`beta`）

1. め: B の角 β は、A − B ＝ (−L, 0) と、C − B ＝ (p − L, h) のなす角よ。
2. め: なす角は、二つのベクトルだけで決まる。だから、二つを原点から描き直して測るわ。
3. め: (−L, 0) の向きは、t → −∞ での q(t) の極限。(p − L, h) の向きは q(p − L) よ。
4. め: だから β ＝ θ(−∞, p − L)。−∞ から p − L までの広義積分になるの。
5. め: 偶関数だから、これは、L − p から ∞ までの積分に等しいわ。
6. ず: 単位円の上では、α の弧が左の端に、β の弧が右の端にあるのだ。

絵:

- 1（地）: B の β（緑の扇形）。(−L, 0) と (p − L, h) の矢印。
- 2（動き）: 二本の矢印が平行移動で原点に集まる。扇形も一緒に動く。
- 3: 直線の上の t ＝ p − L の点と q(p − L)。(−1, 0) に白丸。
- 4: 単位円で (−1, 0) から q(p − L) までの弧（緑）。グラフの (−∞, p − L] を緑で塗る。式。
- 5（動き）: 面積と弧が折り返され、[L − p, ∞) と、q(L − p) から (1, 0) までの弧になる。式 β ＝ ∫_{L−p}^{∞}。
- 6: 単位円の上の青い弧（左の端）と緑の弧（右の端）。あいだは空いている。

### 3-7 γ（`gamma`）

1. め: C の角 γ は、A − C ＝ (−p, −h) と、B − C ＝ (L − p, −h) のなす角よ。
2. め: (x, y) を (x, −y) に移す写像は、x 軸についての折り返し。内積を変えないから、なす角も変えないわ。
3. め: 二つを折り返すと、(−p, h) と (L − p, h)。向きは q(−p) と q(L − p) になるの。
4. め: L ＞ 0 だから −p ＜ L − p。γ ＝ θ(−p, L − p) で、−p から L − p までの積分よ。
5. ず: 単位円の上では、γ の弧が、α の弧と β の弧のあいだに、すき間なくはまるのだ！

絵:

- 1（地）: C の γ（紫の扇形）。二本の矢印を原点から描き直す（下向き）。
- 2（動き）: 二本の矢印が、x 軸について上へ折り返される。扇形も一緒に返る。式 ⟨Sx, Sy⟩ ＝ ⟨x, y⟩。
- 3: 矢印の先が、直線 y ＝ h の上の −p と L − p に届く。q(−p) と q(L − p)。
- 4: 単位円の弧（紫）と、グラフの [−p, L − p] の面積（紫）。式。
- 5: 単位円の上で、青、紫、緑の弧が並び、すき間がなくなる。

### 3-8 内角の和（`whole`）

1. め: 三つを足すわ。積分区間は、−∞ から −p、−p から L − p、L − p から ∞。
2. め: 隣どうしは端の一点だけを共有して、合わせると実数全体になる。だから、和は −∞ から ∞ までの積分になるの。
3. め: h/(t² ＋ h²) の原始関数は、arctan(t/h) よ。
4. め: t → ∞ で π/2 に、t → −∞ で −π/2 に近づくから、積分の値は π になるわ。
5. ず: α ＋ β ＋ γ ＝ π。証明 2 も、できたのだ！
6. め: 同じことを、単位円の上でも確かめておくわ。−∞ から ∞ までの積分は、q(t) が通る弧の長さよ。
7. め: q(t) は、両端を除いた上半円を、ちょうど一度通る。その長さは、半周の π なの。

絵:

- 1（地）: 三つの式（青、紫、緑）。下の t の数直線に三つの区間。
- 2（動き）: 区間が一本につながる。式 ∫_{−∞}^{∞} h/(t² ＋ h²) dt。
- 3: 式 ∫ h/(t² ＋ h²) dt ＝ arctan(t/h) ＋ C と、微分して確かめる一行。
- 4: 極限の値。式 π/2 − (−π/2) ＝ π。
- 5: 式 α ＋ β ＋ γ ＝ π を枠で囲み、□。
- 6（動き、別の図）: q(t) が左の端から右の端まで動き、通った弧が、青、紫、緑の順に上半円を埋める。
- 7: 上半円に「π」（1-2 の半周と同じ印）。

### 3-9 平行線の証明（`parallel`）

1. め: 証明 2 を、もう一つの図で見ておくわ。原点と、(−p, h)、(L − p, h) の二点を結ぶの。
2. ず: 三角形 ABC を、C が原点に来るように平行移動して、x 軸について折り返した形なのだ。
3. め: この三角形で、x 軸は、C を通って辺 AB に平行な直線になっているわ。
4. め: 原点で、x 軸の負の向きと、A への向きのなす角は、−∞ から −p までの積分。これは α に等しかったわね。
5. め: A の内角と、平行線と辺 CA が作る角は、錯角。偶関数で書き換えた所は、錯角が等しいことを示していたの。
6. め: β も同じ。原点のまわりで、三つの角は x 軸の上側をすき間なく埋めて、合わせて π になるわ。
7. ず: 平行線を引く中学の証明の、一つずつの段階が、積分の式になっていたのだ。
8. ず: 当たり前の定理なのに、ずいぶん準備がいったのだ。たしかに、難解だったのだ。

絵:

- 1（地）: 3-8 の最後の絵。原点から (−p, h) と (L − p, h) へ線分。三角形ができる。
- 2（動き）: 3-1 の三角形 ABC（薄く）が平行移動し、x 軸について折り返って重なる。頂点の名前 C（原点）、A、B が付く。
- 3: x 軸と辺 AB に、平行の印。
- 4: 原点の、x 軸の負の向きと CA のあいだの角（青）。式 ∫_{−∞}^{−p}。
- 5: A の内角 α（青）と、原点の角（青）を、錯角の形で結ぶ。3-5 の書き換えの式を小さく添える。
- 6: β も同じ（緑）。原点で、青、紫、緑が x 軸の上側の半円を埋め、「π」。

```text
【証明1】

1. 角度の定義
R² に通常の内積を導入する。
単位円 S¹ = {(x,y) ∈ R² | x²+y²=1} を考え、角度を単位円上の有向弧の長さによって定義する。
単位円の一周は 2π である。
回転は弧の長さと向きを保存するため、回転を合成したとき、その回転角は 2π を法として加算される。

2. 三角形の辺ベクトル
A, B, C を反時計回りに並ぶ3点とし、u = B - A, v = C - B, w = A - C と定義する。
これらは u + v + w = 0 を満たす。
また、3点が反時計回りに並び、一直線上にないため、det(u,v) > 0 である。
w = -u-v より、det(v,w) = det(u,v) > 0, det(w,u) = det(u,v) > 0 も成立する。

3. 回転角の和
u から v、v から w、w から u への反時計回りの回転角を、それぞれ θ₁, θ₂, θ₃ とする。
各行列式が正なので、0 < θ₁, θ₂, θ₃ < π である。
3つの回転を順に合成すると、最初の方向に戻る。
したがって、その回転角の和は 2π の整数倍となる。 θ₁ + θ₂ + θ₃ = 2kπ（k は整数）
一方、0 < θ₁ + θ₂ + θ₃ < 3π なので、この範囲で可能な整数は k=1 のみである。
よって、θ₁ + θ₂ + θ₃ = 2π

4. 内角との関係
三角形の内角を α, β, γ とする。
各頂点の内角と、対応する辺ベクトルの回転角は、互いに補角の関係にある。
すなわち、α = π - θ₃, β = π - θ₁, γ = π - θ₂ である。
したがって、α + β + γ = 3π - (θ₁ + θ₂ + θ₃) = 3π - 2π = π
ゆえに、α + β + γ = π が成立する。□

【証明その2】

1. 座標の設定
座標軸の平行移動と回転により、任意の三角形の頂点を A = (0,0), B = (L,0), C = (p,h) と表せる。
ただし L>0、h>0、p∈R である。各頂点の内角を α, β, γ とする。

2. 角度の積分表示
実数 t に対して、単位ベクトル q(t) = (t,h) / √(t²+h²) を考える。これは単位円の上半分を動く点を表す。
微分すると、q'(t) = (h²,-ht) / (t²+h²)^(3/2) となる。
したがって、その速さは |q'(t)| = h / (t²+h²) である。
ラジアンは単位円の弧の長さによって定義されるので、2つの方向 (a,h)、(b,h) がなす角は、a<b のとき、
θ(a,b) = ∫[a,b] h/(t²+h²) dt と表せる。

3. 内角の計算
頂点 A の角 α は、正の x 軸と (p,h) のなす角である。したがって、α = ∫[p,∞] h/(t²+h²) dt
被積分関数が偶関数であることから、α = ∫[-∞,-p] h/(t²+h²) dt を得る。
次に、頂点 B の角 β は、負の x 軸と (p-L,h) のなす角である。よって、β = ∫[-∞,p-L] h/(t²+h²) dt
偶関数の性質から、β = ∫[L-p,∞] h/(t²+h²) dt となる。
最後に、頂点 C から A、B へ向かうベクトルは、(-p,-h), (L-p,-h) である。
両者を x 軸について反射しても、なす角は変わらない。したがって、γ = ∫[-p,L-p] h/(t²+h²) dt である。

4. 内角の和
以上より、α + β + γ = ∫[-∞,-p] + ∫[-p,L-p] + ∫[L-p,∞]（被積分関数はどれも h/(t²+h²)）
積分区間は実数全体を重複なく覆うので、α + β + γ = ∫[-∞,∞] h/(t²+h²) dt
ここで、∫ h/(t²+h²) dt = arctan(t/h) + C であるから、
α + β + γ = lim[t→∞] arctan(t/h) - lim[t→-∞] arctan(t/h) = π/2 - (-π/2) = π
ゆえに、α + β + γ = π が成立する。□
```
